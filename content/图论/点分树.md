#图论 #点分治 
## 概述
点分树，又叫动态点分治，核心思想是把点分治的每一层的重心重构为一棵树。

由于点分树的高度为 $log~n$，每一层重心管辖的点数为 $O(n)$，可以高效地储存各点信息。

![[Pasted image 20230905181854.png]]

### 性质：
1. 对于任意两点 $u,v$，**唯一**可以确定的是 $u,v$ 在点分树上的 LCA **一定在 $u\to v$ 的路径上**；换句话说，$dis(u,v)=dis(u,lca)+dis(lca,v)$。

## 例题
### [P6329 【模板】点分树 | 震波](https://www.luogu.com.cn/problem/P6329)
**题意：**

动态维护对于距离某个点小于 $k$ 的点的权值和。

**题解：** 

先建立点分树，对于每个重心 $u$，用树状数组维护 $f(u,k)$ 表示与$u$ 距离为 $k$ 的点的权值和。

查询时，沿着点分树往上查，答案加上与 $p$ 距离为 $y-dis(u,p)$ 的点的权值和。

但是，父亲统计答案时会重复统计儿子已经统计了的，因此，还需维护 $g(u,k)$ 表示与 $u$ 的父亲距离为 $k$ 且在 $u$ 子树内的点的权值和（在 $u$ 子树内指在重心 $u$ 管辖范围内），统计答案时减去即可。

修改点值时直接暴力修改 $log~n$ 次即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define pb push_back
const int N=1e5+5;
int n,m,a[N],la,ty,x,y,rt,maxx,SZ,sz[N],vis[N],dis[N],fa[N],t,q[N],l;
vector<int>e[N],f[N],g[N],d[N];
void add(int *tr,int L,int k,int v){for(;k<=L;k+=k&-k) tr[k]+=v;}
int ask(int *tr,int k){int re=0;for(;k;k-=k&-k) re+=tr[k];return re;}
void grt(int u,int fa){
	sz[u]=1,q[++t]=u;int mx=0;
	for(int v:e[u])if(v!=fa&&!vis[v]) grt(v,u),sz[u]+=sz[v],mx=max(sz[v],mx);
	mx=max(mx,SZ-sz[u]);
	if(mx<maxx) rt=u,maxx=mx;
}
void calc(int u,int fa){
	for(int v:e[u])if(!vis[v]&&v!=fa) dis[v]=dis[u]+1,calc(v,u);
}
void solve(int u){
	vis[u]=1,f[u].resize(maxx+1);
	if(fa[u]){
		g[u].resize(SZ+1);
		for(int i=1;i<=t;++i) add(g[u].data(),SZ,dis[q[i]],a[q[i]]);
	}
	dis[u]=0,calc(u,u);
	for(int i=1;i<=t;++i)if(q[i]!=u)
		add(f[u].data(),maxx,dis[q[i]],a[q[i]]),d[q[i]].pb(dis[q[i]]);
	reverse(d[u].begin(),d[u].end());
	int tot=SZ;//!!! 注意，点分治的正确写法，之前一直写错了(虽然复杂度没大问题)
	for(int v:e[u])if(!vis[v])
		SZ=maxx=(sz[v]>sz[u]?tot-sz[u]:sz[v]),//!!!
		t=0,grt(v,v),fa[rt]=u,solve(rt);
}
void work(){
	scanf("%d%d%d",&ty,&x,&y),x^=la,y^=la,l=0;
	if(ty){
		for(int u=x;fa[u];u=fa[u]){
			add(f[fa[u]].data(),f[fa[u]].size()-1,d[x][l],y-a[x]);
			add(g[u].data(),g[u].size()-1,d[x][l],y-a[x]);
			++l;
		}
		a[x]=y;return ;
	}
	la=a[x]+ask(f[x].data(),min(y,(int)f[x].size()-1));
	for(int u=x;fa[u];u=fa[u]){
		if(y-d[x][l]>=0)
			la+=ask(f[fa[u]].data(),min(y-d[x][l],(int)f[fa[u]].size()-1))
			+a[fa[u]]-ask(g[u].data(),min(y-d[x][l],(int)g[u].size()-1));
		++l;
	}
	printf("%d\n",la);
}
int main(){
	scanf("%d%d",&n,&m);
	for(int i=1;i<=n;++i) scanf("%d",&a[i]);
	for(int i=1;i<n;++i) scanf("%d%d",&x,&y),e[x].pb(y),e[y].pb(x);
	SZ=maxx=n,grt(1,1),solve(rt);
	while(m--) work();
	return 0;
}
```
### [P3241 [HNOI2015] 开店](https://www.luogu.com.cn/problem/P3241)
**题意：** 给定一颗 $n(n≤150000)$ 个点的树，每个点有点权，边有边权。$q(q≤200000)$ 次询问，每次询问点权在 $[L,R]$ 之间的所有点到某个点的距离之和。强制在线。

**题解：** 

板子题。

建点分树后用 vector 维护 $f_u$ 表示 $u$ 子树内年龄小于等于 $k$ 的个数与距离和。

同理，记录 $g_u$ 表示 $u$ 子树内年龄小于等于 $k$ 的个数与到 $fa_u$ 的距离和。

因题目有特殊条件 “这个树所有顶点的度数都小于或等于 $3$ ”，可以不维护 $g$，询问时直接找，常数可以小一点。（当然，常规写法开 O2 也能过）

### [P4292 [WC2010] 重建计划](https://www.luogu.com.cn/problem/P4292)
**题意：** 给定一棵有边权的树，求长度为 $[L,R]$ 的平均权值最大的路径。

**题解：** 

考虑暴力，先二分平均权值，将边权置为 $w_i-mid$，再 $n^2$ dfs 判断是否有合法路径边权和非负。

由于是路径问题，考虑点分治，维护 $u$ 的每一棵子树的深度为 $k$ 的最大权值和，依次合并即可求出合法路径边权和的最大值。

但是，可以构造一个长度为 $\frac23n$ 的长链，在中点处构造一个 $\frac13n$ 的菊花，此时点分治的复杂度就被卡成 $O(n^2logn)$。

因此，我们要对 $u$ 的子树按深度升序排序。

于是我们可以得到：[Unaccepted 90](https://www.luogu.com.cn/record/124008874)的好成绩。

容易发现，每次二分都要重复找重心，更新路径权值，十分繁琐，于是可以上点分树，常数将大大减小：[Accepted 100](https://www.luogu.com.cn/record/124011062)。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define db double
#define pb push_back
const int N=1e5+5;
const db eps=1e-4;
int n,L,R,x,y,w,vis[N],rt,SZ,mx,sz[N],t,mxl,la,he,ta,p,q[N];
db l,r,mi,s[N],ans;
struct edge{int v,w;};
vector<edge>e[N];
vector<vector<db>>a[N];
vector<int>id[N];
void grt(int u,int fa){
	sz[u]=1;int maxx=0;
	for(edge i:e[u])if(i.v!=fa&&!vis[i.v]) grt(i.v,u),sz[u]+=sz[i.v],maxx=max(maxx,sz[i.v]);
	maxx=max(maxx,SZ-sz[u]);
	if(maxx<mx) mx=maxx,rt=u;
}
void dfs(int u,int fa,int c,db d){
	for(edge i:e[u])if(i.v!=fa){
		if((int)a[rt][t].size()==c) a[rt][t].pb(d+i.w);
		else a[rt][t][c]=max(a[rt][t][c],d+i.w);
		if(!vis[i.v]) dfs(i.v,u,c+1,d+i.w);
	}
}
void solve(int u){
	vis[u]=1,t=-1,a[u].resize(e[u].size());
	for(edge i:e[u]){
		a[u][++t].pb(i.w),id[u].pb(t);
		if(!vis[i.v]) dfs(i.v,u,1,i.w);
	}
	sort(id[u].begin(),id[u].end(),[](int x,int y){return a[rt][x].size()<a[rt][y].size();});
	int tot=SZ;
	for(edge i:e[u])if(!vis[i.v])
		SZ=mx=(sz[i.v]>sz[u]?tot-sz[u]:sz[i.v]),grt(i.v,i.v),solve(rt);
}
void work(int u){
	t=id[u].size()-1;
	for(int i=0;i<=t;++i){
		int ll=a[u][i].size();
		for(int j=0;j<ll;++j) a[u][i][j]-=mi*(j+1);
	}
	if(t>=0){
		mxl=min(R,(int)a[u][id[u][0]].size());
		for(int i=0;i<mxl;++i) s[i]=a[u][id[u][0]][i];
	}
	for(int i=1;i<=t;++i){
		p=1,he=1,ta=0;
		for(int j=mxl;j;--j){
			while(p+j<=R&&p<=(int)a[u][id[u][i]].size()){
				while(he<=ta&&a[u][id[u][i]][q[ta]-1]<=a[u][id[u][i]][p-1]) --ta;
				q[++ta]=p,++p;
			}
			while(he<=ta&&j+q[he]<L) ++he;
			if(he<=ta) ans=max(ans,s[j-1]+a[u][id[u][i]][q[he]-1]);
			s[j-1]=max(s[j-1],a[u][id[u][i]][j-1]);
		}
		la=mxl,mxl=min(R,(int)a[u][id[u][i]].size());
		for(int j=mxl;j>la;--j) s[j-1]=a[u][id[u][i]][j-1];
	}
	for(int i=L;i<=mxl;++i) ans=max(ans,s[i-1]);
	for(int i=0;i<=t;++i){
		int ll=a[u][i].size();
		for(int j=0;j<ll;++j) a[u][i][j]+=mi*(j+1);
	}
}
int check(){
	ans=-1e18;
	for(int i=1;i<=n;++i) work(i);
	return ans>=-1e-12;
}
int main(){
	scanf("%d%d%d",&n,&L,&R);
	for(int i=1;i<n;++i)
		scanf("%d%d%d",&x,&y,&w),r=max(r,(db)w),e[x].pb((edge){y,w}),e[y].pb((edge){x,w});
	SZ=mx=n,grt(1,1),solve(rt);
	while(l+eps<r){
		mi=(l+r)/2;
		if(check()) l=mi;
		else r=mi;
	}
	printf("%.3lf",l);
	return 0;
}
```
