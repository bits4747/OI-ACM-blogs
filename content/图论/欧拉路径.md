#图论 
## 定义
通过图中所有边恰好一次的通路称为**欧拉通路**。

通过图中所有边恰好一次的回路称为**欧拉回路**（出发并回到原点）。

具有欧拉回路的无向图或有向图称为**欧拉图**。

具有欧拉通路但不具有欧拉回路的无向图或有向图称为**半欧拉图**。

感性理解：**欧拉图**就是从任意一个点开始都可以一笔画完整个图，**半欧拉图**必须从某个点开始才能一笔画完整个图。
## 判定
1. 存在**欧拉回路**
- 无向图：图所有顶点度数都为偶数且图是**连通图**。
- 有向图：所有顶点的入度等于出度且图是**连通图**。
2. 存在**欧拉通路**
- 无向图：图中只有2个点(或0个点)度数为奇数且图是**连通图**。
- 有向图：最多只能有两个点入度不等于出度，且其中一个点的出度恰好比入度大1（作为起点），另一个的入度比出度大1（作为终点），图是**连通图**。

## 例题
### 模板[#10105. 「一本通 3.7 例 1」欧拉回路](https://loj.ac/p/10105)
```cpp
const int N=1e5+5,M=4e5+5;
int t,n,m,x,y,h[N],nxt[M],to[M],tot=1,b[M],in[N],ou[N],fl,st;
void add(int u,int v){
	nxt[++tot]=h[u],to[tot]=v,h[u]=tot;
}
stack<int>s;
void dfs(int u,int la){
	for(int i=h[u];h[u];i=nxt[i]){
		h[u]=nxt[i];
		if(b[i]) continue;
		if(t==2) dfs(to[i],i-1);
		else b[i^1]=1,dfs(to[i],(i>>1)*((i&1)?-1:1));
	}
	s.push(la);
}
int main() {
	t=read(),n=read(),m=read();
	for(int i=1;i<=m;++i){
		x=read(),y=read();
		add(x,y),++in[y],++ou[x];
		if(t==1) add(y,x),++in[x],++ou[y];
	}
	if(t==1) for(int i=1;i<=n;++i) if(in[i]&1){fl=1;break;}
	if(t==2) for(int i=1;i<=n;++i) if(in[i]!=ou[i]){fl=1;break;}
	if(fl){
		printf("NO");
		return 0;
	}
	dfs(to[2],0),s.pop();
	if(s.size()<m){
		printf("NO");
		return 0;
	}
	printf("YES\n");
	while(!s.empty()){
		printf("%d ",s.top()),s.pop();
	}
    return 0;
}
```

1. $cnt=0$：$1$ 次 。

### [#10111. 「一本通 3.7 练习 5」相框](https://loj.ac/p/10111)
用并查集分连通块，记得独立单点，不统计贡献。

- 对于单个连通块：
1. 如果一个焊点度数大于2，必须烧熔。
1. 每两对奇点必须相连。

- 合并多个连通块：
1. 若有奇点，可忽略，处理奇点可以顺便合并
1. 否则，若有焊点度数大于2，在单个连通块烧熔时可以多分出两个奇点，奇点数 +2。 
1. 再否则，要熔断一个度数为2的点并与其他合并，ans+2。
