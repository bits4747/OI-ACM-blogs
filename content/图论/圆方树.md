#图论 #Tarjan 
## 概述
对于有环无向图，可以通过建圆方树利用树（森林）的良好性质。（类似于有向图缩点后建 DAG，但由于无向图一点可能属于多个点双连通分量，需要用到圆方树）

在圆方树中，原来的每个点对应一个 **圆点**，每一个点双对应一个 **方点**。

对于每一个点双连通分量，它对应的方点向这个点双连通分量中的每个点连边。  

每个点双形成一个“菊花图”，多个“菊花图”通过原图中的割点连接在一起（因为点双的分隔点是割点）。

因此，圆方树中每条边连接一个圆点和一个方点。

![[Pasted image 20230322220806.png]]

其实这是广义圆方树（把一条边连接两个点也看成一个点双，只存在圆方边），狭义圆方树存在圆圆边和圆方边（~~但感觉没什么用~~）。

### [P4630 [APIO2018] 铁人两项](https://www.luogu.com.cn/problem/P4630)
![[Pasted image 20230323071909.png]]
#### 点双的重要性质
对于一个点双中的两点，它们之间 **简单路径** 的 **并集**，恰好完全等于这个点双。

证明：
![[Pasted image 20230323071015.png]]

**题解：**

在 $s$ 和 $f$ 确定时，$c$ 的备选数量就等于 **从 $s$ 到 $f$ 所有简单路径的并的大小减二** （要把 $s$ 和 $f$ 去掉）。

![[Pasted image 20230323071109.png]]
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5,M=2e5+5;
#define pb push_back
int n,m,x,y,nd,tim,low[N],dfn[N],a[M],sz[M];
long long ans,f[M];
vector<int>vec[N],e[M];
stack<int>st;
void tarjan(int u,int fa){//就是在求点双/割点的同时顺便建圆方树
	//注：其实可以省略fa及v==fa的判断，因为对判断low[v]>=dfn[u]没有影响
	//而且通常在仙人掌上v==fa是环上连接的两点，需要进行一些操作
	low[u]=dfn[u]=++tim,st.push(u);
	for(int v:vec[u]){
		if(v==fa) continue;
		if(!dfn[v]){
			tarjan(v,u),low[u]=min(low[u],low[v]);
			if(low[v]>=dfn[u]){
				++nd;
				do{
					x=st.top(),st.pop(),e[x].pb(nd),e[nd].pb(x),++a[nd];
				}while(x!=v);
				++a[nd],e[u].pb(nd),e[nd].pb(u);
			}
		}
		else low[u]=min(low[u],dfn[v]);
	}
}
void dfs(int u,int fa){
	if(u<=n) sz[u]=1,f[u]=a[u];
	for(int v:e[u])if(v!=fa)
		dfs(v,u),ans+=f[u]*sz[v]+f[v]*sz[u],sz[u]+=sz[v],f[u]+=f[v]+1ll*a[u]*sz[v];
}
int main(){
	scanf("%d%d",&n,&m),nd=n;
	for(int i=1;i<=n;++i) a[i]=-1;
	for(int i=1;i<=m;++i) scanf("%d%d",&x,&y),vec[x].pb(y),vec[y].pb(x);
	for(int i=1;i<=n;++i)if(!dfn[i]) tarjan(i,i),st.pop(),dfs(i,i);
	printf("%lld",ans<<1);
	return 0;
}
```
### [P4606 [SDOI2018]战略游戏](https://www.luogu.com.cn/problem/P4606)
![[Pasted image 20230323072112.png]]

**题解：**

先建出圆方树，则变为询问 $S$ 在圆方树上对应的连通子图中的圆点个数减去 $|S|$。

如何计算连通子图中的圆点个数？有一个方法：

把圆点的权值放到它和它的父亲方点的边上，问题转化为求边权和，这个问题可以参考 [[LCA#[ 10132. 「一本通 4.4 例 3」异象石](https://loj.ac/p/10132)]] 的一种解法。 

即把 $S$ 中的点按照 DFS 序排序，计算排序后相邻两点的距离和（还包括首尾两点之间的距离），答案就是距离和的一半，因为每条边只被经过两次。

最后，如果子图中的深度最浅的节点是圆点，答案还要加上 $1$，因为我们没有统计到它。

### [CF487E Tourists](https://www.luogu.com.cn/problem/CF487E)
![[Pasted image 20230323072638.png]]

**题解：**

同样地，我们建出原图的圆方树，令方点权值为相邻圆点权值的最小值，问题转化为求路径上最小值，路径最小值可以使用树链剖分和线段树维护。

但是，修改一次一个圆点的点权，需要修改所有和它相邻的方点，这样很容易被卡到 $O(nq)$ 个修改。

这时我们利用圆方树是棵 **树** 的性质，令方点权值为自己的儿子圆点的权值最小值，这样的话修改时 **只需要修改父亲方点**。

对于方点的维护，只需要对每个方点开一个 `multiset` 维护权值集合即可。

需要注意的是查询时若 LCA 是方点，则还需要查 LCA 的父亲圆点的权值；若 LCA 是圆点点，则还需要查自己的权值。

### [P5236 【模板】静态仙人掌](https://www.luogu.com.cn/problem/P5236)
圆方树建图。

**如何连边权：**

定义一个环的根为这个环上 $dfn$ 序最小的点，那么每个点和方点之间的边权就是这个点和环的根的最短距离。

圆方树建完后长这样：（注：未加粗的表示方点）

![[Pasted image 20230323131259.png]]

**如何找到环上两点的最短距离：**

由于是仙人掌（任意一条边至多只出现在个环上），可以在 tarjan 过程中记录每个在环上的点的下一条边，在建方点时维后缀和（从点双的根顺时针走的距离），前缀距离（逆时针）就是深度 - 根的深度。与方点连边时边权为以上两种走法的较小值。

![[Pasted image 20230323130532.png]]
```cpp
void tarjan(int u){
	low[u]=dfn[u]=++tim,st[++t]=u;
	for(node i:vec[u]){//v==fa也不能跳过（见else）
		if(!dfn[i.v]){
			pd[i.v]=pd[u]+i.w,tarjan(i.v),low[u]=min(low[u],low[i.v]);
			if(low[i.v]<dfn[u]) ed[u]=i.w;
			if(low[i.v]>=dfn[u]){
				++nd,x=0,y=t;
				do{sd[st[t]]=(x?sd[x]:0)+ed[st[t]],x=st[t];}while(st[t--]!=i.v);
				t=y;
				do{
					x=min(sd[st[t]],pd[st[t]]-pd[u]),e[nd].pb((node){st[t],x}),e[st[t]].pb((node){nd,x});
				}while(st[t--]!=i.v);
				e[u].pb((node){nd,0}),e[nd].pb((node){u,0});
			}
		}
		else if(dfn[i.v]<low[u]) ed[u]=i.w,low[u]=dfn[i.v];//环上最后一点与根的边（只有两个点的点双中两点的连边）
	}
}
```
建完树后，对于询问 $x,y$：

1. 若 $lca$ 为圆点，$ans=dis[x]+dis[y]-dis[lca]*2$；

2. 若 $lca$ 为方点， $ans=dis(x,sonx)+dis(y,sony)+dis(sonx,sony)$，其中 $sonx,sony$ 为 $x,y$ 到 $lca$ 的路径上离 $lca$ 最近的点，$sonx,sony$ 在同一个环上，其距离可根据之前维护的前后缀距离计算。

### [P6335 [COCI2007-2008#1] STAZA](https://www.luogu.com.cn/problem/P6335)
题目要求 “路线可以从任何城市开始，但必须在城市 $1$ 结束。” 等价于 “路线从 $1$ 开始，可以在任何城市城市结束。” 

由于是仙人掌图，可以先建圆方树，一个环内的边可以都走。

定义 $f_i$ 表示 $i$ 子树内从 $i$ 出发并且可以回到 $i$ 可走边数的最大值，$g_i$ 表示 $i$ 子树内从 $i$ 出发并且无需回到 $i$ 可走边数的最大值进行 DP。

对于一个 $u$ 为根的环上，$f_u+=\sum_{v\in circle_u}f_v+len_{circle_u}$，$g_u$ 则可以顺时针、逆时针走一遍，找到从环上一个点出去的最大值。

**注意：**

1. 若一个点双内只有两个点（即狭义圆方树中圆圆边连接的点）不是环。

2. 由于一个点可以是多个环的根，对于每一个环应该记录 $cg$（走 $g$ 比走 $f$ 多的），最后 $g_u=f_u+cg$。

3. 注意当 $low_v>dfn_u$ 时，$(u,v)$ 是非环边，$cg=max(cg,g[v]+1)$。

4. 可以不用显性建出圆方树，直接 DP。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5,M=2e5+5;
#define pb push_back
int n,m,x,y,tim,low[N],dfn[N],t,st[N],f[N],g[N];
vector<int>vec[N];
void tarjan(int u,int fa){
	low[u]=dfn[u]=++tim,st[++t]=u;int cg=0;
	for(int v:vec[u])if(v!=fa){
		if(!dfn[v]){
			tarjan(v,u),low[u]=min(low[u],low[v]);
			if(low[v]>dfn[u]) cg=max(cg,g[v]+1);
			if(low[v]>=dfn[u]){
				int ff=1,mf,gg=0,tt=t;
				do{
					gg=max(gg,ff+g[st[t]]),ff+=f[st[t]]+1;
				}while(st[t--]!=v);
				if(tt-t==1){cg=max(cg,gg-ff);continue;}
				f[u]+=ff,mf=ff,t=tt;
				do{
					ff-=f[st[t]]+1,gg=max(gg,ff+g[st[t]]);
				}while(st[t--]!=v);
				cg=max(cg,gg-mf);
			}
		}
		else low[u]=min(low[u],dfn[v]);
	}
	g[u]=cg+f[u];
}
int main(){
	scanf("%d%d",&n,&m);
	for(int i=1;i<=m;++i) scanf("%d%d",&x,&y),vec[x].pb(y),vec[y].pb(x);
	tarjan(1,1);
	printf("%d",max(f[1],g[1]));
	return 0;
}
```
