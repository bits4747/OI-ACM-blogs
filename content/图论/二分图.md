#图论 #网络流

## 二分图匹配
**图的匹配：**

选出 $E'$，使得任意两个边没有公共端点。

- **最大匹配：** 边数最多的匹配。
- **最大权匹配：** 边权之和最大的匹配。
- **完美匹配：** 所有点都是被匹配的一个匹配。
- **准完美匹配：** 只有一个点不被匹配的匹配。

## 二分图最小点覆盖
**图的点覆盖：** 选出 $V'$，使得每条边都至少有一个端点被选择。
### 定理：二分图最大匹配数=二分图最小点覆盖
最大匹配中的边是独立的，所以覆盖最大匹配中的每条匹配边都至少要 $1$ 个点。

一个匹配的两个端点 $u,v$ 中，最多只有一个端点（假设为 $u$）有闲置边（即 $E(u,x)$，其中 $x$ 不在匹配中），否则舍弃当前匹配 $u,v$ 即可新增两个配，与 “最大匹配”矛盾。因此，每条匹配边最多要选一个点。

## 二分图最大独立集
**图的独立集：** 选出 $V'$，使得任意两个点没有连边。
### 定理：二分图最大独立集=总点数−二分图最小点覆盖
独立集为点覆盖的补集。

点覆盖的补集没有相连的点（根据定义），即为独立集。由于点覆盖最小，独立集最大。
## Hall 定理

^10646c

对于一个二分图 $G(X,Y)$，$X$ 存在一个匹配（即左边的每个点都能被匹配上）的充分必要条件为对于 $X$ 的任意子集 $S$，$S$ 的邻居个数 $N(S)$ 必须 **大于等于** $|S|$。特别的，如果 $|X|=|Y|$，则此时存在完美匹配。

### [CF793G Oleg and chess](https://www.luogu.com.cn/problem/CF793G)
不考虑复杂度就是经典二分图匹配，在没有矩阵的地方行连列。

但是 $n\le 1e4$，$n^2$ 连边跑网络流啥都会寄。

由于每一行都是连若干段列，考虑线段树扫描线优化建图。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int X=1e4+5,N=6e5+10,M=24e5;
int n,m,xa,ya,xb,yb,x,y,ty,rt,nd=1,ls[N],rs[N],sz[N],id[N];
int cnt=1,h[N],no[N],nx[M],v[M],w[M],d[N],ans;
struct op{int x,y;};
vector<op>s[X],t[X];
void add(int x,int y,int W){nx[++cnt]=h[x],h[x]=cnt,v[cnt]=y,w[cnt]=W;}
void adde(int x,int y,int W){add(x,y,W),add(y,x,0);}
queue<int>q;
void bfs(){
	for(int i=0;i<=nd;++i) d[i]=-1;
	d[0]=0,q.push(0);int u;
	while(!q.empty()){
		u=q.front(),q.pop();
		for(int i=h[u];i;i=nx[i])if(w[i]&&d[v[i]]==-1) d[v[i]]=d[u]+1,q.push(v[i]);
	}
}
int dfs(int u,int f){
	if(u==1) return f;
	for(int &i=no[u];i;i=nx[i])if(w[i]&&d[u]+1==d[v[i]]){
		int ff=dfs(v[i],min(w[i],f));
		if(ff) return w[i]-=ff,w[i^1]+=ff,ff;
	}
	return 0;
}
void dinic(){
	while(1){
		bfs();
		if(d[1]==-1) break;
		for(int i=0;i<=nd;++i) no[i]=h[i];
		int f;
		while((f=dfs(0,n))) ans+=f;
	}
}
void build(int &k,int l,int r){
	k=++nd,id[k]=k;
	if(l==r){adde(nd,1,1);return ;}
	int mi=(l+r)>>1;
	build(ls[k],l,mi),build(rs[k],mi+1,r);
	adde(id[k],id[ls[k]],n),adde(id[k],id[rs[k]],n);
}
void change(int k,int l,int r){
	if(x<=l&&r<=y){sz[k]+=ty,id[k]=(sz[k]?-1:k);return ;}
	int mi=(l+r)>>1;id[k]=++nd;
	if(x<=mi) change(ls[k],l,mi);
	if(y>mi) change(rs[k],mi+1,r);
	if(~id[ls[k]]) adde(id[k],id[ls[k]],n);
	if(~id[rs[k]]) adde(id[k],id[rs[k]],n);
}
int main(){
	scanf("%d%d",&n,&m);
	for(int i=1;i<=m;++i){
		scanf("%d%d%d%d",&xa,&ya,&xb,&yb);
		s[ya].push_back((op){xa,xb}),t[yb+1].push_back((op){xa,xb});
	}
	build(rt,1,n);
	for(int i=1;i<=n;++i){
		for(op j:t[i]) x=j.x,y=j.y,ty=-1,change(rt,1,n);
		for(op j:s[i]) x=j.x,y=j.y,ty=1,change(rt,1,n);
		++nd,adde(0,nd,1),adde(nd,id[rt],1);
	}
	dinic();
	printf("%d",ans);
	return 0;
}
```
### <font color="#ff0000">★</font> [P2570 [ZJOI2010]贪吃的老鼠](https://www.luogu.com.cn/problem/P2570)
二分时间 $T$，奶酪有效期变为 $[ll_i,rr_i+T]$。

对于每一块奶酪，与源点连边容量为 $p_i$。（非常常规）

对时间点离线排序，分成最多 $2*n-1$ 个时间段，每个时间段内可以吃的奶酪（奶酪有效期包含当前时间段的奶酪）和可以吃的时间（记为 $x$）一定。

把老鼠的速度从大到小排序并差分（$cf_i=sp_i-sp_{i+1}$），则第 $i$ 只老鼠的速度可以表示为 $\sum_{j=i}^{m}cf_j$。

每个时间段 $x$内，把老鼠 $i$（按速度排序后的编号）向汇点连边，容量为 $x*i*cf_i$；再把时间段内可以吃的奶酪向老鼠连边，容量为 $x*cf_i$。（非常神仙）

感性理解为何这样连边可以保证 **“在任一时刻，一只老鼠最多可以吃一块奶酪，一块奶酪最多被一只老鼠吃”** ：
1. 由于时间可以无限分割，老鼠可以瞬移吃奶酪，只要保证老鼠 $i$ 吃奶酪的总时间不超过 $x$，即可保证 **“在任一时刻，一只老鼠最多可以吃一块奶酪”**。由于第 $i$ 只老鼠的速度可以表示为 $\sum_{j=i}^{m}cf_j$，老鼠和汇点连边的容量为 $x*i*cf_i$，可以保证**老鼠 $i$ 吃奶酪的总时间不超过 $x$**。贪心地想，先让速度快的老鼠吃最优，当 $i$ 到汇点的边满流时前 $i$ 只老鼠都吃饱了，单只老鼠的时间在流量的限制下都为 $x$（虽然残量网络上不一定是这样，但可以等价地把后面的流引到前面）。
2. 由于第 $i$ 只老鼠的速度可以表示为 $\sum_{j=i}^{m}cf_j$，奶酪和老鼠连边的容量为 $x*cf_i$，则限制了 $\le i$ 及的老鼠在一个奶酪上最多不重叠地吃 $x$ 时间，$i=m$ 时则 **“在任一时刻，一块奶酪最多被一只老鼠吃”。**

```cpp
int check(){
	cnt=1;
	for(int i=0;i<=en;++i) h[i]=0;
	for(int i=1;i<=n;++i) t[i]=ll[i],t[i+n]=mi+rr[i],adde(0,i,p[i]);
	tt=n<<1,sort(t+1,t+1+tt);
	for(int i=1;i<tt;++i){
		x=t[i+1]-t[i];
		if(x<eps) continue;
		for(int j=1;j<=m;++j){
			id=n+(i-1)*m+j,adde(id,en,x*cf[j]*j);
			for(int k=1;k<=n;++k)if(ll[k]-eps<=t[i]&&t[i+1]<=rr[k]+mi+eps)
				adde(k,id,x*cf[j]);
		}
	}
	ans=0,dinic();
	return abs(ans-sum)<eps;
}
void solve(){
	scanf("%d%d",&n,&m),sum=0,en=n+(2*n-1)*m+1;
	for(int i=1;i<=n;++i) scanf("%d%d%d",&p[i],&ll[i],&rr[i]),sum+=p[i];
	for(int i=1;i<=m;++i) scanf("%d",&sp[i]);
	sort(sp+1,sp+1+m,greater<int>()),sp[m+1]=0;
	for(int i=m;i;--i) cf[i]=sp[i]-sp[i+1];
	l=0,r=sum/sp[1];
	while(l+1e-6<r){
		mi=(l+r)/2;
		if(check()) r=mi;
		else l=mi; 
	}
	printf("%.5lf\n",l);
}
```
