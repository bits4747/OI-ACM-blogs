## [【XR-3】Unknown Mother-Goose](https://www.luogu.com.cn/problem/P5539)
**题意：**

小 X 得到了一个正整数 $n$ 和一个正整数集合 $S$，他想知道有多少个正整数 $x$ 满足以下所有条件：

*   $3 \le x \le n$
*   存在 $a \in S, x \equiv 0 \pmod a$
*   存在 $b \in S,x-1 \equiv 0 \pmod b$
*   存在 $c \in S,x-2 \equiv 0 \pmod c$

请你帮小 X 求出来。

**题解：**

开一个 $10^9$ 的数组，对于 $S$ 中的每个数 $k$，把 $k$ 的倍数都设为 $1$，统计数组中有多少组 $3$ 个连续的 $1$，手写 $64$ 位 bitset 优化一下。

复杂度 $\Theta(\frac{n|S|}w)$。

**注意：**

1. 当 $k$ 很小时，处理其倍数的复杂度接近 $O(n)$。但因为 $64\times k≡0\pmod{64}$，每 $64$ 个 bitset 位就是一个循环，可以处理出循环节。
2. $x$ 是正整数，要把第 $0$ 项的贡献判掉。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ull unsigned long long
const int N=(1000000000>>6)+5;
const ull _63=1ull<<63,_62=1ull<<62;
ull a[N],t[65];
int n,nn,m,s,ans;
void work(){
	scanf("%d",&s);
	if(s>64) for(int i=s;i<=n;i+=s) a[i>>6]|=1ull<<(i&63);
	else{
		memset(t,0,sizeof(t));
		for(int i=(s<<6);i>=0;i-=s) t[i>>6]|=1ull<<(i&63);
		for(int i=0;i<=nn;)
			for(int j=0;j<s&&i<=nn;++j,++i) a[i]|=t[j];
	}
}
int C(ull x){int re=0;while(x)re+=(x&1),x>>=1;return re;}
int main(){
	scanf("%d%d",&n,&m),nn=n>>6;
	while(m--) work();
	if((n&63)!=63) a[nn]=((1ull<<((n&63)+1))-1)&a[nn];
	a[0]&=-2ull;
	for(int i=0;i<=nn;++i) ans+=C(a[i]&(a[i]>>1)&(a[i]>>2));
	for(int i=1;i<=nn;++i)
		ans+=((a[i]&1)&&(a[i]&2)&&(a[i-1]&_63))+((a[i]&1)&&(a[i-1]&_63)&&(a[i-1]&_62));
	printf("%d\n",ans);
	return 0;
}
```
