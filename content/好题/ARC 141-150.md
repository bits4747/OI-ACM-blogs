## [B - Two LIS Sum](https://atcoder.jp/contests/arc149/tasks/arc149_b)
**题意：** 

给定 $n$ 个二元组 $(A_i ,B_i)$ ，其中 $A[1...n]$ 和 $B[1...n]$ 为  $1...n$ 的排列，可任意交换相邻的两个二元组任意次，使得 $LIS(A)+LIS(B)$ 最大。

**题解：**

能够交换相邻的 $(A_i ,B_i)$ 意味着可以自由地重新排列 $N$ 个二元组 $(A_i ,B_i)$ 。

我们可以证明，在一个最优解中，对于任何 $i$，$A_i$ 和 $B_i$ 中至少有一个被用作 $LIS$ 的一个元素。我们也可以证明，存在一个最优解，其中 $A$ 是升序排列的。

**证明：**

若仅 $A_i$ , $A_{i+1}$ 有序， $B_i$ , $B_{i+1}$ 逆序，是否调换贡献都为 $1$。

若仅 $A_i$ , $A_{i+1}$ 逆序， $B_i$ , $B_{i+1}$ 有序，是否调换贡献都为1。

若两者有序，贡献为 $2$，调换为 $0$。

若两者逆序，调换贡献为 $2$，否则为 $0$。

所以 $A$ 升序排列结果不坏。

按 $A$ 升序排列，用树状数组维护 $B$ 的 $LIS$ 即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=3e5+5;
int n,tr[N],f[N],ans;
struct node{
	int a,b;
}s[N];
bool cmp(node x,node y){return x.a<y.a;}
int lowbit(int x){return x&-x;}
void add(int x,int y){for(;x<=n;x+=lowbit(x)) tr[x]=max(tr[x],y);}
int ask(int x){int sum=0;for(;x;x-=lowbit(x)) sum=max(tr[x],sum);return sum;}
int main(){
	scanf("%d",&n);
	for(int i=1;i<=n;++i) scanf("%d",&s[i].a);
	for(int i=1;i<=n;++i) scanf("%d",&s[i].b);
	sort(s+1,s+1+n,cmp);
	for(int i=1;i<=n;++i){
		f[s[i].b]=ask(s[i].b-1)+1;
		add(s[i].b,f[s[i].b]);
		ans=max(ans,f[s[i].b]);
	}
	printf("%d",ans+n);
	return 0;
}
```
