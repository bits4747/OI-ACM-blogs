## [CF1579G Minimal Coverage](https://www.luogu.com.cn/problem/CF1579G)
### 题意：
- 给你 $n$ 条线段，告诉你每条线段的**长度**。
- 你需要把它们放在一条**无限长的数轴**上。
- 放置需满足**当前线段的起点**是**前一个线段的终点**，特别的第一个线段的起点为 $0$。

也就是说，若前一个线段的终点是 $x$,当前长度为 $d$, 那么这个线段必须放在 $[x-d,x]$ 终点变为 $x-d$，或 $[x, x + d]$ 终点变为 $x + d$。请问放置完后所有线段的最小覆盖长度是多少？

$1\le n\le 10^4$，$1\le a_i \le1000$
### 题解：
- <font size=5 color=red>答案一定小于 $2*maxlen$ </font>
    在原点左边往右放，右边往左放。
    这个性质可以大大缩小线段位置的范围（$1e7-->2e3$），就可以愉快地 $DP$ 了。（没想到qwq）
- $f_{i,j}$ 表示到 $i$ 线段距离最左边为 $j$ ，距离最右边的最小距离

```cpp
for(int i=1;i<=n;++i)
	for(int j=0;j<=mx;++j){
		if(j>=a[i]) f[i][j]=min(f[i][j],max(0,f[i-1][j-a[i]]-a[i]));
		if(j+a[i]<=mx) f[i][j]=min(f[i][j],f[i-1][j+a[i]]+a[i]);
	}
```

## [CF1540B Tree Array](https://www.luogu.com.cn/problem/CF1540B)
### 题意：
给定一棵 $n$ 个节点的树。  

1. 等概率选择一个根，并对这个节点打上标记（初始时没有节点被打上标记）；
2. 从根开始等概率选择一个节点拓展（有标记的才可以对外拓展），并对这个节点打上标记；

所有节点编号按照节点被打上标记的时间排序后的形成序列，求生成序列的期望逆序对数对 $10^9+7$ 取模后的值。  

$2\leq n\leq200$ 
### 题解：
可以想到把不同根的情况分开处理。

对于每一个有根树，考虑算出每一个逆序对 $(a,b)$ 的贡献<font size=5 color=red> (只需考虑 $a$ 比 $b$ 先的概率，$a>b$ )</font>。

<font size=5 color=red> 发现拓展到 $lca$ 处前和 $lca$ 外的点对概率无影响，概率只与 $lca$ 子树内 $a,b$ 的深度有关。</font>

相当于有两个栈（把 $lca$ 到 $a,b$ 的两条链放入栈中），栈底为 $a,b$ ，每次有 $1/2$ 概率从任意一个栈取出，问先取空一个栈的概率。

显然这只与栈的大小有关。

预处理出 $f_{i,j}$ ，表示 $a,b$ 的深度为 $i,j$ 时，先到 $a$ 的概率。

<font size=4 color=red> 注意：由于多次 $dfs$ ，求 $lca$ 时 $st$ 表一定要完全覆盖，不然会寄。</font>

## [CF1322B Present](https://www.luogu.com.cn/problem/CF1322B)
### 题意：
- 给出一个长度为 $n$ 的数列 $a$。其中第 $i$ 项为 $a_i$。
- 请你求出 $\bigoplus_{i=1}^{n}\bigoplus_{j=i+1}^{n}(a_i+a_j)$。其中 $\oplus$ 表示按位异或操作。
- $2 \leq n \leq 4 \times 10^5$，$1 \leq a_i \leq 10^7$。
### 题解：
显然，对答案套路地按位考虑。

第 $i$ 位为 $1$ 当且仅当任意两数之和第 $i$ 位为 $1$ 的对数个数之和为奇数。

难点在于如何求 “两数之和第 $i$ 位为 $1$ 的对数个数” 。

考虑两数 $a,b$ 之和的第 $i$ 位为 $1$ 的情况，发现只与 $a,b$ 的前 $i$ 位有关，记 $a,b$ 的前 $i$ 位的和为 $sum$ ，满足以下情况第 $i$ 位为 $1$。（注：第 $i$ 位指从低到高的第 $i$ 位）
1. $2^i \le sum < 2^{i+1}$
2. $sum\ge 2^{i+1}+2^i$

记 $sum\ge 2^{i}$ 的对数为 $s1$，$sum\ge 2^{i+1}$ 的对数为 $s2$，$sum\ge 2^{i+1}+2^i$的对数为 $s3$，两数之和第 $i$ 位为 $1$ 的对数个数即为 $s1-s2+s3$。

$s1,s2,s3$ 可以对 $a$ 数组按前 $i$ 位大小排序后双指针求。

## [CF963B Destruction of a Tree](https://www.luogu.com.cn/problem/CF963B)
### 题意：
给你一棵树，如果树上的节点有偶数条边与它相连，则这个节点是可删除的，删除这个节点后所有与之相连的边也将删除。判断一棵树是否可以依次删除所有节点。

$n\le 2e5$
### 题解：
显然，要去掉叶子节点只能删掉叶子节点的父亲。因此，最优方案一定是从下到上一层一层删点。

## [CF734E Anton and Tree](https://www.luogu.com.cn/problem/CF734E)
### 题意：
给一棵 $n$ 个节点的树，每个点为黑色或白色，一次操作可以使一个相同颜色的连通块变成另一种颜色，求使整棵树变成一种颜色的最少操作数。

$n\le 2e5$
### 题解：
<font size=5 color=red> 缩点后任意选一个节点作为根，通过不断变换根所在的连通块的颜色就可以让整颗树变为同一颜色，需要的操作数就是树中距根距离最大的节点。</font>

因此，只需要求出缩点后树的直径就可以确定根。

可以把两端颜色不同的边赋值为 $1$，相当于保留这条边，进行巧妙地缩点。

## [CF1151E Number of Components](https://www.luogu.com.cn/problem/CF1151E)
### 题意：
有一条$n(1 \leq n \leq 10^5)$个节点的链，编号相邻节点有边，每个点一个权值$a_i(1 \leq a_i \leq n)$，$f(l,r)$定义为权值在$[l,r]$的点中的连通块数量求$\sum_{l=1}^{n}\sum_{r=l}^{n}f(l,r)$
### 题解：
<font size=5 color=red>连通块数=点数-边数，因此，答案为点出现次数总和-相邻两点都出现的次数。</font>

$a_i$ 出现当且仅当 $l\le a_i 且 a_i\le r$ 。

短小精悍：
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5;
int n,a[N];
long long ans;
int main(){
	scanf("%d",&n);
	for(int i=1;i<=n;++i) scanf("%d",&a[i]),ans+=1ll*a[i]*(n-a[i]+1);
	for(int i=1;i<n;++i) ans-=1ll*min(a[i],a[i+1])*(n-max(a[i],a[i+1])+1);
	printf("%lld",ans);
	return 0;
}
```

## [CF1379F2 Chess Strikes Back (hard version)](https://www.luogu.com.cn/problem/CF1379F2)
### 题意：
给出一个 $2n\times2m$ 的黑白交错棋盘，其中格子 $(1,1)$ 为白色。每次拿走或放回一个白格，问能否在剩下的白格中放入 $n\times m$ 个国王使得它们不互相攻击。
### 题解：
把棋盘四个一组分，可以发现一组内一定要选一个白色，靠近左上角的块都要选左上角的白色，靠近左上角的块都要选右下角的白色（当然可以全选一种）。

因此，只需维护限制后不能选左上白色的最靠近左上角的块 $A$ 和不能选右下白色的最靠近右下角的块 $B$，若块 $A$ 在 $B$ 的左上方（包括同行同列）则无解。

线段树维护。
![在这里插入图片描述](https://img-blog.csdnimg.cn/949cd1247e5e4621bddbd53cdedc3048.jpeg#pic_center)
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2e5+5;
int n,m,q,lmn[N<<2],rmx[N<<2],f[N<<2],p;
pair<int,int>t;
map<pair<int,int>,int>mp;
set<int>sl[N],sr[N];
#define fi first
#define se second
#define ls k<<1
#define rs k<<1|1
void change(int k,int l,int r){
	if(l==r){
		lmn[k]=(sl[l].empty()?1e9:*sl[l].begin());
		rmx[k]=(sr[l].empty()?0:*sr[l].rbegin());
		f[k]=(lmn[k]<=rmx[k]);
		return ;
	}
	int mi=(l+r)>>1;
	if(p<=mi) change(ls,l,mi);
	else change(rs,mi+1,r);
	lmn[k]=min(lmn[ls],lmn[rs]),rmx[k]=max(rmx[ls],rmx[rs]),f[k]=f[ls]|f[rs]|(lmn[ls]<=rmx[rs]);
}
int main(){
	scanf("%d%d%d",&n,&m,&q);
	memset(lmn,127,sizeof(lmn));
	for(int i=1;i<=q;++i){
		scanf("%d%d",&t.fi,&t.se),p=(t.fi+1)>>1;
		if(!mp[t]) (t.fi&1)?sl[p].insert((t.se+1)>>1):sr[p].insert((t.se+1)>>1);
		else (t.fi&1)?sl[p].erase((t.se+1)>>1):sr[p].erase((t.se+1)>>1);
		mp[t]^=1,change(1,1,n);
		if(f[1]) printf("NO\n");
		else printf("YES\n");
	}
	return 0;
}
```
