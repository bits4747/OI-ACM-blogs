1. 手枪用 $a_i$ 次+狙击枪 $1$ 次，花费 $a_i*r1+r3$。
2. 分两次
    1. 激光枪 $1$ 次+手枪 $1$ 次，花费 $r1+r2$。
    2. 手枪用 $a_i+2$ 次，花费 $(a_i+2)*r1$。

注：以上花费不计转移花费 $d$。

情况 $2$ 可以和相邻关卡组队反复横跳，也可以跳过去马上又跳回来。

## [CF1671F Permutation Counting](https://www.luogu.com.cn/problem/CF1671F)

这里有一个优化。由于 $g$ 中有值的很少（$148$个），可以把有值的存下来，大大加速转移。

最后每次询问统计答案：$$ans+=C(n-j+i,i)*f[i][j][X][K]$$

## [CF1572B Xor of 3](https://www.luogu.com.cn/problem/CF1572B)
麻烦的构造题。

手玩出有效操作：当三个数内只存在一个 $1/0$ 时，可以把整段变成 $1/0$。

详见代码。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2e5+5;
int t,n,sum,la,a,len,o,fl,cnt,em,s[N],pr[N],tmp,tot,ans[N];
int main(){
	scanf("%d",&t);
	while(t--){
		scanf("%d",&n),la=-1,sum=em=len=fl=cnt=tot=0;
		for(int i=1;i<=n;++i){
			scanf("%d",&a),sum+=a;
			if(a!=la&&i!=1) s[++cnt]=len,pr[cnt]=pr[cnt-1]+s[cnt],len=0;
			la=a,++len;
		}//01分段  
		s[++cnt]=len,pr[cnt]=pr[cnt-1]+s[cnt]; 
		for(int i=2-(a^(cnt&1));i<=cnt;i+=2){//对0段操作,用这段0清除前面的1 
			if(!s[i-1]){em=1;continue;}
			if(!(s[i-1]&1)){//前面1为偶数，可以全部消掉 (110)
				tmp=pr[i-1]+1;em=1;
				while(tmp>=pr[i-1]-s[i-1]+3) ans[++tot]=tmp,tmp-=2;
				continue;
			}//前面1为奇数 
			if(s[i]&1){//若0为奇数，可以把这段0变成1(100)，消掉101后往前消
				//111000001...  111111101... 111111000...
				if(i==cnt){fl=1;break;}//后面没有1可以借无解 
				tmp=pr[i-1]+2;
				while(tmp<pr[i]) ans[++tot]=tmp,tmp+=2;
				--s[i+1],tmp=pr[i]+1;//后面1减1 
				while(tmp>=pr[i-1]-s[i-1]+3) ans[++tot]=tmp,tmp-=2;
				em=1;
			}
			else{//若0为偶数，直接把整段变成1和前后连起来 
				tmp=pr[i-1]+2;
				while(tmp<=pr[i]) ans[++tot]=tmp,tmp+=2;
				if(i!=cnt) s[i+1]+=s[i]+s[i-1];
				else s[++cnt]=s[i]+s[i-1],a=1;
			}
		}
		if(fl){printf("NO\n");continue;}
		if(a){//如果最后1前面有0且为偶数可以消掉 
			if(!em||s[cnt]&1){printf("NO\n");continue;}
			tmp=n-s[cnt]+2;
			while(tmp<=n) ans[++tot]=tmp,tmp+=2;
		}
		printf("YES\n%d\n",tot);
		for(int i=1;i<=tot;++i) printf("%d ",ans[i]-2);
		printf("\n");
	}
	return 0;
}
```
## [CF1608D Dominoes](https://www.luogu.com.cn/problem/CF1608D)
可以观察到合法方案 $W$ 的个数和 $B$ 的个数必须相等为 $n$。

可行方案：

1. 全 $BW$。
2. 全 $WB$。
3. 当存在 $BB$ 和 $WW$ 至少一个时，$BW$ 和 $WB$ 任意。（由于 $W$ 的个数和 $B$ 的个数必须相等，$BB$ 和 $WW$ 的个数也必须相等）

统计输入里 $?$ 个数 $cq$，$B$ 个数 $cb$，答案为

$$C_{cq}^{n-cb}-del+wb+bw$$

$del$ 指不存在 $BB$ 和 $WW$ 的方案数。

#include<bits/stdc++.h>

const int N=3e5+5;

			s1=s2=0;
			for(int j=0;j<m;++j){
				s1+=(c[(i&1)*2+(j&1)]!=a[i][j]);
