## [[BalticOI 2015] File Paths](https://www.luogu.com.cn/problem/P6843)
**题意：**

给定一棵大小为 $N+M(N,M\le3e3)$ 的树及其边权，你可以在树中加上一条长为 $S(S\le1e6)$ 的有向边，对于每个叶子节点问：是否能构造出一条从根节点出发以该节点为终点的长为 $K(K\le1e6)$ 的路径。

**题解：**

对于叶子 $x$：

1. 不加边就行。
2. 加一条边 $(u,v,S)$，满足 $d_u+S+(d_x-d_v)=K,u\notin \text{叶子},\text{v 为 x 祖先}$。记录 $d_u+S$，对于每个叶子枚举 $v$。
3. 加一条边 $(u,v,S)$，满足 $d_x+a\times (d_v-d_u+S)=K,root\to u\to v\to x$。在 dfs 时，每到一个非叶子节点 $u$ 就再把以它为根的子树遍历一遍，把所有合法的 $d_v-d_u+S$ 记录下来，并在回溯时清除贡献，枚举 $K-d_x$ 的所有约数判断即可。

## [[eJOI2019] 塔](https://www.luogu.com.cn/problem/P6241)
**题意：**

从序列中选择一段**连续**序列，将序列和加入序列，求最小操作次数生成 $n(n\le1e18)$。（初始可生成 $1$）

**题解：**

发现如果每次生成新数都选择整个序列，则序列为 $1,1,2,4,8,16,32\dots$，而选择少加 $1$ 在过去 $k$ 次后会变成少加 $2^{k-2}$（另 $2^{-1}=1$），例如 $1,1,2,3,7,14,28\dots$，因此需要 $\lceil\log_2n\rceil$ 次。

## [[CEOI2010 day2] mp3player](https://www.luogu.com.cn/problem/P6520)
![](Pasted%20image%2020231020093211.png)

**题解：**

由于既不能倒着推，$t$ 也没单调性不能二分，只能将考虑最暴力的做法，即枚举 $t$ 和初始音量正着推。

在 $t$ 确定时，初始音 $V_1$ 单调不降，可以二分。现在瓶颈在枚举 $t$ 上。

不妨先判断 $t$ 有无对应的 $V_1$​ 符合题意，求出最大的 $t$ 后再去二分 $V_1$​。

![](Pasted%20image%2020231020095840.png)

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ls k<<1
#define rs k<<1|1
const int N=4e5+5;
char c;
int n,m,v,lt,ti,x,tr[N],l[N],r[N];
struct op{int ty,t,id;}s[N];
bool cmp(op x,op y){return x.t>y.t;}
int F(int x){return max(l[1],min(r[1],tr[1]+x));}
void build(int k,int L,int R){
	if(L==R){r[k]=m,tr[k]=s[L].ty;return ;}
	int mi=(L+R)>>1;build(ls,L,mi),build(rs,mi+1,R);
	l[k]=min(r[rs],max(l[rs],l[ls]+tr[rs])),r[k]=max(l[rs],min(r[rs],r[ls]+tr[rs])),tr[k]=tr[ls]+tr[rs];
}
void change(int k,int L,int R){
	if(L==R){tr[k]=0;return ;}
	int mi=(L+R)>>1;
	if(s[x].id<=mi) change(ls,L,mi);
	else change(rs,mi+1,R);
	l[k]=min(r[rs],max(l[rs],l[ls]+tr[rs])),r[k]=max(l[rs],min(r[rs],r[ls]+tr[rs])),tr[k]=tr[ls]+tr[rs];
}
int main(){
	freopen("music.in","r",stdin);
	freopen("music.out","w",stdout);
	scanf("%d%d%d",&n,&m,&v);
	for(int i=1;i<=n;++i) scanf(" %c%d",&c,&ti),s[i].ty=(c=='+'?1:-1),s[i].t=ti-lt,lt=ti,s[i].id=i;
	build(1,1,n),sort(s+1,s+1+n,cmp);
	if(F(0)<=v&&v<=F(m)) return printf("infinity"),0;
	while(x<n){
		++x,change(1,1,n);
		while(s[x+1].t==s[x].t&&x<n) ++x,change(1,1,n);
		if(F(0)<=v&&v<=F(m))for(int j=m;~j;--j)if(F(j)==v) return printf("%d %d",s[x].t-1,j),0;
	}
	return 0;
} 
```
## [[COI2007] Policija](https://www.luogu.com.cn/problem/P4334)
**题意：**

一个 $N\le1e5,M\le5e5$ 的无重边的无向图，$Q\le3e5$ 次询问，每次询问删掉一条边或删掉一个点后两个点是否联通。

**题解：**

建广义圆方树。

- 删掉一个点后两个点是否联通：删掉的点不在两点路径上即可联通。
- 删掉一条边后两个点是否联通：一条边若不在点双连通分量内（即割边），它就会变成一个方点，并连接其原来的两个点。因此，转化为问题一。

## [[BalticOI 2015] Tug of War](https://www.luogu.com.cn/problem/P4733)
![](Pasted%20image%2020231020104242.png)
![](Pasted%20image%2020231020104306.png)

**题解：**

我们把人当作边建图，当且仅当连通块的边数刚好等于点数时有解，因此每个连通块独立且为基环树。

对于一个连通块，树的部分确定，环只有两种选择（顺逆时针），且两种选择相反，造成的力量值差互为相反数。

观察发现，不同力量差值个数是 $\sqrt{ns}$ 级别的（和为 $ns$ 的连续段长度），我们记录每个环的力量值差 $s_i$，合并相同的权值做分组背包，先二进制优化再 bitset 优化，复杂度小于 $O(\frac{\sqrt{ns}\times ns\times\log (ns)}{32})$。

## [[BalticOI 2015] Editor](https://www.luogu.com.cn/problem/P4732)
![](Pasted%20image%2020231020115743.png)

**题解：**

操作 $i$ 可能撤销的操作的 $p$ 是单调不减的，可对每个 $i$ 维护一个单调栈。

设第 $i$ 次撤销操作要撤销的是 $j$，那么 $(i,j)$ 的操作中不存在优先级比 $i$ 小的，即这段操作都不会加入到单调栈 $i$ 中，$i$ 的单调栈是 $j-1$ 的单调栈加入 $i$ 的。

因此，用主席树维护单调栈即可。
