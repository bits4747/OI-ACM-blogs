## [CF786A Berzerk](https://www.luogu.com.cn/problem/CF786A)
定义 $f[0][i],f[1][i]$ 为人A、人B 在 $i$ 处先手是否必胜。

根据“**能转移到必败态的状态就是必胜态，只能转移到必胜态的状态就是必败态**”，且已知 $f[0][1]=f[1][1]=0$ , 可逆推出怪物在每个星球任何人先手的胜败情况。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=7005;
int n,m[2],a[2][N],f[2][N],vis[2][N],cnt[2][N];
void dfs(int u,int ty){
	if(vis[ty][u]) return;
	vis[ty][u]=1;
	for(int i=1;i<=m[ty^1];++i){
		int v=(u+n-a[ty^1][i]-1)%n+1;
		if(v==1) continue;
		if(!f[ty][u]) f[ty^1][v]=1,dfs(v,ty^1);//能转移到必败态的状态就是必胜态
		else if(++cnt[ty^1][v]==m[ty^1]) f[ty^1][v]=0,dfs(v,ty^1);//只能转移到必胜态的状态就是必败态
	}
}
int main(){
	ios::sync_with_stdio(false);
	cin>>n>>m[0];
	for(int i=1;i<=m[0];++i) cin>>a[0][i];
	cin>>m[1];
	for(int i=1;i<=m[1];++i) cin>>a[1][i];
	for(int i=1;i<=n;++i) f[0][i]=f[1][i]=0;
	dfs(1,0),dfs(1,1);
	for(int j=0;j<2;++j){
		for(int i=2;i<=n;++i){
			if(!vis[j][i]){cout<<"Loop ";continue;}
			if(f[j][i]){cout<<"Win ";continue;}
			cout<<"Lose ";
		}
		cout<<"\n";
	}
	return 0;
}
```

## [CF1202C You Are Given a WASD-string...](https://www.luogu.com.cn/problem/CF1202C)
容易想到答案最优情况为：
$$ (xma-mix+1)*(may-miy+1)-max(xma-mix+1,may-miy+1) $$ 

但最后不一定能让 $x$ 和 $y$ 的范围缩小 $1$ 。

由于上下和左右是一样的，只考虑上下（W、S），即改变 $y$ 的范围。

由于改变最大、最小是一样的，只考虑把 $y$ 的最大值变小。

$may$ 必须要在 **$may$ 第一次出现之前**且在 **$miy$ 最后一次出现之后**改变。

记 $bmay$ 为 $may$ 可否改变， $bmiy$ 同理，则有：

```cpp
if(s[i]=='W'){//上
	++y;
	if(y==may) bmiy=0;
	if(y>may) may=y,bmay=1;
}
if(s[i]=='S'){//下
	--y;
	if(y==miy) bmay=0;//在miy最后一次出现之后
	if(y<miy) miy=y,bmiy=1;
}
```
同时，注意 $x$ 、 $y$ 的范围至少为 $1$ 。
