## [[ARC160E] Make Biconnected](https://www.luogu.com.cn/problem/AT_arc160_e)
**题意：**

给你一棵由无向边组成的树，点的度数不超过 $3$，树上每个点有权值 $w_i$。你可以把两个点之间连边，代价是 $w_u+w_v$。请给出一种连边方式，使图是一个点双连通图，求最小代价。

$1\ \leq\ \sum N\ \leq\ 2\ \times\ 10^5$

**题解：**

> 巧妙的构造

显然，每个叶子节点都要连边，最节约的办法就是让其互相连边。

当叶子节点为偶数个时，两两配对；为奇数时，剩下一个与合适且最小的连边。

可以发现，任意相连的两点在树上的原路径必须有交点。（为了路径与外界点断连时可以通过交点连接外界）

因此，我们两两配对时尽量让 dfs 序相差较远的叶子节点相连，即 $id_i\to id_{i+\frac{cnt}2}$。

考虑奇数点时剩下的点要如何连边。可以发现，沿点 $u$ 一直往外走知道第一次遇到度数为 $3$ 的点的路径上的点（包括）都不能连，因为因为连完后还是有链（一条链连着含 $u$ 的环），不是点双。

我们求出最小点 $v$，可以发现，若 $v$ 在叶子节点 $u_1$ 的绝路上，就一定不会在 $u_2$ 的绝路上。因此，似乎只需求最小点就行了，再随便选一个合法叶子与其匹配即可。

但是，有特殊情况：一个度数为 $3$ 的菊花图，若最小点为重心，则需要与次小点相连。

## [[ARC159F] Good Division](https://www.luogu.com.cn/problem/AT_arc159_f)
**题意：**

定义一个序列是好的当且仅当可以每次删去一对相邻不同的数把序列删空。

现在给定一个长度为 $2n$ 的序列 $A$，计数划分方式使得每一段都是好的。

$1\ \leq\ N\ \leq\ 5\ \times\ 10^5,1\ \leq\ a_i\ \leq\ 2N$

**题解：**

首先，若一段区间有绝对众数则不是好区间，反之。

考虑 $n^2$ DP，定义 $f_i$ 为以 $i$ 结尾的方案数，记录 $\sum f_i$ 减去不合法的来转移。

考虑如何快速求出不合法的 $f_i$ 之和。

> 绝对众数常见 Tricks：
> 
> 判断 $x$ 是否为绝对众数只需把 $x$ 设为 $1$，其余数设为 $0$，若区间和大于 $0$ 则有。 

因此，对于一个数 $x$，我们把它们全部选出来并在原数列中删去，每个 $x$ 再在剩下的数中选出其位置前后的两个数并将其从原数列删去。

我们发现，只有在选出来的序列中，或者说选出来的序列的连续段中（段与段不可能连起来使得 $x$ 为绝对众数），$x$ 才有可能是绝对众数。

对于多个数，我们可以对每个数进行如上操作，把每个数对应的若干连续段离线储存下来。可以发现，所有段的总长度是 $O(n)$ 级别的。

对于每一个连续段，计算前缀和（$x$ 为 $1$，其余为 $0$），放入树状数组维护，即可求出不合法的 $f_i$ 和。

时间复杂度 $O(n\log n)$。
## [[ARC158D] Equation](https://www.luogu.com.cn/problem/AT_arc158_d)
**题意：**

$T$ 组数据。每组数据给定一正整数 $n$ 和一不小于 $5$ 的素数 $p$。

试构造三元组 $(x,y,z)$ 满足：

1. $1 \le x < y < z \le p - 1$

2. $(x+y+z)(x^n+y^n+z^n)(x^{2n}+y^{2n}+z^{2n}) \equiv x^{3n}+y^{3n}+z^{3n} (\bmod \space p)$

能够证明解一定存在。

题目保证 $1 \le T \le {10}^5$，$1 \le n,p \le {10}^9$，$p$ 是素数。

**题解：**

令 $F(x,y,z),G(x,y,z)$ 分别位等式左右边。

因为 $F(tx,ty,tz)=t^{3n+1}F(x,y,z)$，$G(tx,ty,tz)=t^{3n}G(x,y,z)$，对于固定的 $(a,b,c)$ ，如果 $F(a,b,c)\ne0$ 且 $G(a,b,c)\ne0$，我们可以令 $t=\frac{G(a,b,c)}{F(a,b,c)}$。

因此，对于 $(a,b,c)$，只需不满足以下任意条件即可快速求出答案：

1. $a,b,c\ne0$。
2. $a\ne b,b\ne c,c\ne a$。
3. $a^i+b^i+c^i\ne0,i\in\{1,2n,3n\}$

我们感觉满足这些条件的 $(a,b,c)$ 很少，不妨随机一下。

事实证明，随机出不满足条件的 $a,b,c$ 概率不超过 $4$。

## [[ARC156D] Xor Sum 5](https://www.luogu.com.cn/problem/AT_arc156_d)
**题意：**

给定 $n$ 个数的数列 $a$ 和一个整数 $k$。
对于所有长度为 $k$，值域为 $[1,n]$ 的数列 $p$，求出 $\sum _{i=1}^{k} a_{p_i}$ 的异或和。

$1\ \leq\ N\ \leq\ 1000$，$1\ \leq\ K\ \leq\ 10^{12}$，$0\ \leq\ A_i\ \leq\ 1000$

**题解：**

转载题解：[click](https://www.luogu.com.cn/blog/279646/arc156d-ti-xie)

![](Pasted%20image%2020231007204933.png)

>Tricks:
> 
> 1. 由 Lucas 定理的推论，$\left(\begin{array}{cc}K\\c_1,c_2,\dots,c_n\end{array}\right)$ 是奇数当且仅当在二进制下 $c_1​,c_2​,\dots,c_n$​ 为 $K$ 的划分。
> 2. 利用多个相同数异或时奇数个数才有效来化简问题。
> 3. 按位统计答案。

**题解代码：**

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=2048,N=51;
int n,a[MAXN];
ll k,f[N+1][MAXN],g[N+1][MAXN];
bool vis[N+1][MAXN];//vis数组表示这个状态的方案数是否大于0
int main() {
    scanf("%d%lld",&n,&k);
    for(int i=1; i<=n; ++i) scanf("%d",&a[i]);
    g[0][0]=vis[0][0]=1;
    for(int i=0; i<N; ++i)
        for(int j=0; j<MAXN; ++j)
            if(vis[i][j]) {//状态要方案数大于0
                if((k>>i)&1) {
                    for(int y=1,x; y<=n; ++y) {//枚举划分的a
                        x=a[y]+(j>>1);
                        g[i+1][x]^=g[i][j];
                        f[i+1][x]^=f[i][j];
                        vis[i+1][x]=true;
                        if(g[i][j]&j&1) f[i+1][x]^=(1ll<<i-1);//方案数为奇数且那一位为1
                    }
                } else {
                	vis[i+1][j>>1]=true;
                	f[i+1][j>>1]^=f[i][j];
                	if(g[i][j]&j&1) f[i+1][j>>1]^=(1ll<<i-1);
                	g[i+1][j>>1]^=g[i][j];
				}
            }
    printf("%lld\n",f[N][0]);
    return 0;
}
```

## [[ARC154D] A + B > C ?](https://www.luogu.com.cn/problem/AT_arc154_d)
**题意：**

有一个隐藏的长度为 $n$ 的排列 $P$。

你可以询问交互库 `? i j k`，交互库会判断 $P_i + P_j > P_k$ 是否为真命题，如果是则回答 `Yes`，否则回答 `No`。你需要在至多 $25000$ 次询问内找出该排列。

交互库不自适应，即排列 $P$ 是一开始就确定的。

$1 \leqslant n \leqslant 2000$。

**题解：**

观察到，询问限制是 $n\log n$ 级别的，且 $p_x+1>y$ 等同于 $p_x\ge p_y$。

因此，只需要找到 $1$ 即可利用 $n\log n$ 次比较求解（手写归并或放入 stable_sort）。

重点在于如何找 $1$。

由于 $1+1>p_x$ 当且仅当 $p_x=1$ 时为真。因此，我们令 $k=1$，$x$ 从 $2\sim n$ 枚举，若 $p_k+p_k>p_x$，则 $p_k\ne 1$，令 $k=x$；否则 $p_k+p_k\le p_x$，则 $p_x\ne 1$。

我们可以通过 $n-1$ 次比较找到 $p_k=1$。

一开始的想法是从低位开始枚举每一位的 $x$ 的最优策略，但由于进位会影响后面高位的决策，贪心有后效性。

因此，我们考虑 DP。定义 $f_{i,j}$ 为考虑到第 $i$ 位，其中有 $j$ 个元素进位的前 $i$ 位最小数字和。

[题解代码](https://www.luogu.com.cn/blog/_post/533089)

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=200005,N=10;
int n;
ll f[MAXN],g[MAXN],a[MAXN],b[MAXN],cnt[N+1];
int main() {
	scanf("%d",&n);
	for(int i=1; i<=n; ++i) {
		scanf("%d",&a[i]);
		f[i]=1e18;
	}
	for(ll x=1; x<1e10; x*=10) {
		for(int i=0; i<=N; ++i)cnt[i]=0;
		for(int i=0; i<=n; ++i) {
			g[i]=f[i],f[i]=1e18;
			if(i)++cnt[a[i]/x%10];
		}
		for(int i=0; i<=n; ++i) {
			if(i) --cnt[a[i]/x%10],++cnt[a[i]/x%10+1];
			if(g[i]<1e18) {
				for(int j=0; j<10; ++j) {
					int tmp=0,sum=0;
					for(int k=0; k<=10; ++k) {
						if(j+k>=10) tmp+=cnt[k],sum+=(j+k-10)*cnt[k];
						else sum+=(j+k)*cnt[k];
					}
					f[tmp]=min(f[tmp],g[i]+sum);
				}
			}
		}
		for(int i=0; i<=N; ++i)cnt[i]=0;
		for(int i=1; i<=n; ++i)++cnt[a[i]/x%10];
		for(int i=1; i<N; ++i) cnt[i]+=cnt[i-1];
		for(int i=1; i<=n; ++i) b[cnt[a[i]/x%10]--]=a[i];
		for(int i=1; i<=n; ++i)a[i]=b[n-i+1],assert(i==1||(a[i]%(10*x))<=(a[i-1]%(10*x)));
	}
	printf("%lld\n",f[0]);
	return 0;
} 
```

## [[ARC152E] Xor Annihilation](https://www.luogu.com.cn/problem/AT_arc152_e)
**题意：**

一条直线上有 $2^N-1$ 个初始坐标分别为 $1 \sim 2^N-1$ 的动点。其中坐标为 $i$ 的点有一个权值 $w_i$，$w_i$ 为 $1 \sim 2^N-1$ 的排列。

现在你要在 $+100^{100^{100}}$ 和 $-100^{100^{100}}$ 坐标处各加一个不超过 $2^N-1$ 非负权值 $Z$，然后 $2^N-1$ 个点会按照下列规则同时从初始坐标开始移动：

- 每个单位时间内，记严格小于一个点的坐标的权值异或和为 $L$，严格大于这个点的权值异或和为 $R$。当 $L < R$ 时，这个点会以 $1$ 个单位长度每个单位时间的速度向右移动；$L > R$ 时则会以同样速度向左移动；$L = R$ 时，这个点会静止不动。

- 当两个点在同一时间到达同一坐标时，这两个点会合并成一个点，新点的权值为两个点权值的异或和。

请求出可以使所有点在 $100^{100}$ 个单位时间内静止下来的 $Z$ 的个数。

（注：$+100^{100^{100}}$ 和 $-100^{100^{100}}$ 处只是增加了 $Z$ 的权值，初始时并没有动点。）

$2 \le N \le 18$

**题解：**

可以发现所有权值的异或和为 $0$（包括首位的 $Z$）。

因此，不妨定义 $s_i$ 为前 $i$ 个权值的异或和，则 $i$ 左边的权值为 $s_{i-1}$，$i$ 右边的权值为 $s_i$。（令 $w_0=w_{2^n}=Z$）

若 $i,i+1$ 碰撞，则需要 $s_{i-1}\le s_i\ge s_{i+1}$（最多一边去等），碰撞后等同于删去 $s_i$。

最后的局面只有两种情况：

1. 所有 $s$ 相等，所有剩余点静止。
2. $s$ 呈谷状，剩余点向两边扩散。

当且仅当 $s_{min}\ge Z$ 时，点可以静止。我们另 $Z=0$，求出 $s$，问题变为求 $Z\oplus s_i\ge Z$ 的 $Z$ 的个数。

对于任意的 $s_i$ 的最高位 $1$，$Z$ 此位不能为 $1$，则答案为 $2^{不是s_i最高位的位数}$。

> Tricks：
> 
> 1. 关注此题总异或和为 $0$ 的性质并加以利用。
> 2. 考虑终止状态。

**题意：**

Takahashi 和 Aoki 在一个长为 $N$ 的数轴上做游戏。初始时，有 $M$ 个位置有棋，$X_i$ 位置上有黑/白棋。Takahashi 先手，两人轮流操作，操作的内容是在数轴上没有棋的位置上放棋，需要满足其颜色与相邻两点（如果不为空）的颜色不同。无法操作则另一人获胜，问谁有必胜策略。

$N\le 10^{18},M\le\min(N,2\times10^5)$

**题解：**

可以观察到初始局面将数轴分成了若干段，不妨算出每一段的 SG 值。

定义 $SG0,SG1,SG2,SG3$ 分别为两端无棋、一端有棋、两端有棋且相等、两端有棋且不等的 SG 值，则：

$$\begin{cases}
SC0_0=0\\
SC1_0=0\\ 
SC2_0=1\\ 
SC3_0=0\\ 
\end{cases}$$

$$\begin{cases}
SC0_x=\operatorname{mex}(SC1_{i-1}\oplus SC1_{x-i})\\

SC3_x=\operatorname{mex}(SC2_{i-1}\oplus SC3_{x-i},SC3_{i-1}\oplus SC2_{x-i})\\ 
\end{cases}$$

则：
$$\begin{cases}
SC0_x=x\bmod2\\
SC1_x=x\\ 
SC2_x=1\\ 
SC3_x=0\\ 
\end{cases}$$

可有归纳法证明：

对于 $SG0_x$，若 $x$ 为奇数，则存在 $\frac{x-1}2\oplus\frac{x-1}2=0$，且两边奇偶性相同，不存在异或值为 $1$ 的；若 $x$ 为偶数则相反。

对于 $SC1_x$，有 $SC1_{x-1}\oplus SC3_{1}=x-1$。

对于 $SC2_x,SC3_x$ 显然。

## [[ARC151F] RGB Card Game](https://www.luogu.com.cn/problem/AT_arc151_f)
**题意：**

小 X 和小 Y 玩 $T$ 轮游戏，有三种石子，二人分别有 $X_1,X_2,X_3$，$Y_1,Y_2,Y_3$ 个。

游戏开始时，小 X 进攻，小 Y 防守，并重复以下过程：

1. 进攻方任意挑一种石子扔掉一个。
2. 防守方可以不操作；也可以扔掉一个相同种类的石子，并互换身份。

先扔完石子的玩家获胜。两人采用最优策略，问谁必胜。

$1\ \leq\ T\ \leq\ 10^5,0\ \leq X_i,Y_i\leq\ 10^{18}$

**题解：**

如果某一堆石子其中一个人没有，那么这一堆是没有用的，直接删去。

如果有两堆石子都已经被拿完了，那么剩下的一堆谁多谁输。

若每人都剩下三堆数量为 $1$ 的石子，当前局面的先手必败。（第一轮后手不拿）

令 $X_i<Y_i$ 的种类数量为 $A_{num}$，满足条件的 $X_i$ 之和为 $A_{sum}$；$X_i>Y_i$ 的种类数量为 $B_{num}$，满足条件的 $Y_i$ 之和为 $B_{sum}$；$X_i=Y_i$ 的种类数量为 $C_{num}$，满足条件的 $X_i$ 之和为 $C_{sum}$。

---

若 $C_{num}=0$：

此时两人的策略可以视为如下：尽早的拿掉自己比对方多的那些堆里的石子，因为一旦对方的某一堆变空了，自己可以一次性把那一堆的自己的石子拿完。

此时先手获胜的条件是 $B_{sum}\leq A_{sum}$。

---

若 $C_{num}=3$：

没有人会主动将一堆自己有的石子拿空，最终游戏会进行到所有堆里的石子都剩下一个。

$C_{sum}$ 为偶数先手胜，否则后手胜。

---

若 $C_{num}=2$：

若只有两堆，$C_{num}$ 为奇数先手胜，偶数后手胜。

> **证明：**
> 
> 若只有两种数量相同的石子，每一轮两人都必定各拿一个，弃权必败。

若有三堆，剩下的一堆谁少谁胜。

> **证明：**
> 
> 两种数量相同的石子胜负局面确定，可能改变局面的是当不同数量的石子中少的一方只剩 $1$ 个石子时，可以选择弃权来改变先后手。主动权在石子数少的一方手中。

---

若 $C_{num}=1$：

若 $A_{num}=2$ 或 $B_{num}=2$，少的一边一定获胜，因为操作一定能变为 $C_{num}=2$ 的情况。

若 $A_{sum}\geq B_{sum}+C_{sum}$，则先手必胜，此时先手每一步一定可以减少 $B_{sum}+C_{sum}$，这样到最后剩下一堆的时候后手一定比先手多；$B_{sum}\geq A_{sum}+C_{sum}$ 则相反，后手必胜。

否则，如果 $A_{sum}​+B_{sum}​+C_{sum}$​ 是奇数，先手获胜；如果是偶数，后手必胜。
