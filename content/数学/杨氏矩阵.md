## 杨图
行列长度递增，可用于表示整数划分。

## 杨表
在杨图上填入 $1\dots n$ 的排列，要求每行每列递增。

![](Pasted%20image%2020231004094806.png)

## 半杨表
在杨图上填入 $n$ 个数，要求每行每列不递减。

## 勾长定理
定义一个点 $i$ 的勾长 $hook_i$ 为其同行右侧、同列下侧（包括自己）的格子个数，$C_\lambda$ 为形态为 $\lambda$ 的杨表的个数，则：

$$C_\lambda=\frac{n!}{\prod \limits_{i\in \lambda} hook_i}$$

## 插入
分为行插入、列插入，只考虑行，列类似。

## 杨表与 LIS / LDS
1. 第一行的长度为最长上升子序列的长度。
2. 第一列的长度为最长下降子序列的长度。
3. 前 $k$ 行的长度为前 $k$ 长上升子序列的长度和。
4. 前 $k$ 列的长度为前 $k$ 长下降子序列的长度和。

**注意：杨表与 LIS / LDS 只有长度关系。如杨表第一行未必是最长上升子序列。**

## RSK 插入算法
### 杨表对
每个排列可以和杨表对 $(P,Q)$ 一一对应，$\pi\longleftrightarrow(P,Q)$。

我们把排列 $\pi$  依次行插入 $P$，在插入 $\pi_i$ 时新增格子对应的 $Q$ 处填上 $i$。

每个排列 $\pi$ 对应一个杨表对 $(P,Q)$，同时若已知一杨表对 $(P,Q)$ 可确认一排列 $\pi$。

### 半杨表对
同理，半杨表就是把 $n$ 个有序 pair $\left(\begin{array}{cc}u_i \\ v_i\end{array}\right)$ 按 $v_i$ 插入 $P$，在 $Q$ 对应新增格子处填上 $u_i$。

也可以将杨表视作插入 $u$ 为 $1\dots n$ 的二元组。

## 重要定理
对于 $\pi\longleftrightarrow(P,Q)$

### 定理 1
> $\pi^R\longleftrightarrow(P^T,?)$

$\pi^R$ 表示排列 $\pi$ 前后颠倒，$P^T$ 为杨表 $P$ 的转置。

### 定理 2
> $\pi^{-1}\longleftrightarrow(Q,P)$

$\pi^{-1}$ 表示 $u,v$ 互换。

#### 证明
我们可以用矩阵 $M$ 表示有序序列对，在 $(u_i,v_i)$ 处 $+1$，则 $\pi^{-1}$ 为 $M^T$。

我们假设序列对无重复（有重复证明也适用），如图，有色部分代表 $1$。

![](Pasted%20image%2020231004163013.png)

考虑如何从 $M$ 到 $P$。我们先关注杨表 $P,Q$ 的第一行是如何得到的。

观察到，$P$ 中 $(1,1)$ 的值为从 $v_1$ 开始的下降子序列 $\{3,1\}$ 的末尾 $v$ 值，$(1,2)$ 为剩下元素的下降子序列 $\{4,3,2\}$ 中的 $2$，$(1,3)$ 则为 $\{4\}$。而 $Q$ 则是这些子序列首位的 $u$ 值。

对应到矩阵上，就是从上到下扫，把每一个左上方没有点的值加入链中，第 $i$ 条链的链尾 $v$ 为 $P_{1,i}$，链首 $u$ 为 $Q_{1,i}$。

![](Pasted%20image%2020231004164632.png)

由于每条链的左上方没有未选的点，$M^T$ 的链不变，只是首尾翻转。因此，$P(M)_1=Q(M^T)_1$，$Q(M)_1=P(M^T)_1$。

此时，我们需要证明每一行都有此性质。

考虑插入杨表的过程，当 $a_x>a_y$ 时，我们把 $a_y$ 留在此行，把 $a_x$ 放到下一行递归求解，但是新增格子处在 $Q$ 中填入的仍是 $a_y.u$。

因此，不妨理解为把原来的 $(a_y.u,a_y.v)$ 变成了 $a_y.u,a_x.v$。对应到矩阵上，就是变为两点右下角折线处。

因此，第 $2\dots \sqrt n$ 行，都与第一行类似。

![](Pasted%20image%2020231004170757.png)

因此，该定理得证。

## 快速求杨表
根据定理 2，我们只需要求 $P$。

由于杨表的行列长度递增，最多只有 $\sqrt n$ 行、$\sqrt n$ 列。再根据定理 1，我们只需要会求杨表的前 $\sqrt n$ 行。

根据行插入的规则，二分加速，复杂度 $O(n\sqrt n\log n)$。

## 杨表个数
- 杨表对：每行每列一个 $1$ 的矩阵
- 半杨表对：矩阵
- 杨表：每行每列一个 $1$ 的对称矩阵
- 半杨表：对称矩阵

可根据这些性质快速求出杨表、半杨表的个数。

当然，也可以暴搜确定杨表形态，用勾长定理计算。

## 例题
### [P3774 [CTSC2017] 最长上升子序列](https://www.luogu.com.cn/problem/P3774)
#### 重要性质
序列大小取反后填入杨表的形态与原序列杨表的转置的形态相同。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define pii pair<int,int>
const int N=5e4+5,M=21e5+5;
int n,q,a[N],ans[M],k,m,sq,tr[N];
vector<pii>Q[N];
void add(int k){for(;k<=n;k+=k&-k) ++tr[k];}
int ask(int k){int re=0;for(;k;k-=k&-k) re+=tr[k];return re;}
struct qwq{
	int y[255][N];
	void upd(int x,int li,int ty){
		if(li>sq) return;
		int l=0,r=y[li][0]+1,mi;
		while(l+1<r){
			mi=(l+r)>>1;
			if((x>=y[li][mi])^ty) l=mi;
			else r=mi;
		}
		swap(x,y[li][r]),y[li][0]=max(y[li][0],r);
		if(x) return upd(x,li+1,ty);
		if(!ty) add(li);
		else if(r>sq) add(r);
		
	} 
}s[2];
int main(){
	scanf("%d%d",&n,&q),sq=ceil(sqrt(n));
	for(int i=1;i<=n;++i) scanf("%d",&a[i]),a[i]=-a[i];
	for(int i=1;i<=q;++i) scanf("%d%d",&m,&k),Q[m].push_back(make_pair(k,i));
	for(int i=1;i<=n;++i){
		s[0].upd(a[i],1,0),s[1].upd(a[i],1,1);
		for(pii j:Q[i]) ans[j.second]=ask(j.first);
	}
	for(int i=1;i<=q;++i) printf("%d\n",ans[i]);
	return 0;
}
```
