#数学 #分块

部分摘自：[数论分块](https://oi-wiki.org//math/number-theory/sqrt-decomposition/) 和 [数学--数论--整除分块（巨TM详细，学不会，你来打我）](https://blog.csdn.net/weixin_43627118/article/details/104024380)
## 简介
数论[[分块]]采用分块思想，可以快速计算一些含有除法向下取整的和式（即形如 $\sum_{i=1}^nf(i)g(\left\lfloor\dfrac ni\right\rfloor)$ 的和式）。当可以在 $O(1)$ 内计算 $f(r)-f(l)$ 或已经预处理出 $f$ 的前缀和时，数论分块就可以在 $O(\sqrt n)$ 的时间内计算上述和式的值。
## 求 r
对于常数 $n$，使得式子

$$
\left\lfloor\dfrac ni\right\rfloor=\left\lfloor\dfrac nj\right\rfloor
$$

成立的最大的满足 $i\leq j\leq n$ 的 $j$ 的值为 $\left\lfloor\dfrac n{\lfloor\frac ni\rfloor}\right\rfloor$。即值 $\left\lfloor\dfrac ni\right\rfloor$ 所在的块的右端点为 $\left\lfloor\dfrac n{\lfloor\frac ni\rfloor}\right\rfloor$。


## 过程
数论分块的过程大概如下：考虑和式

$\sum_{i=1}^nf(i)\left\lfloor\dfrac ni\right\rfloor$

那么由于我们可以知道 $\left\lfloor\dfrac ni\right\rfloor$ 的值成一个块状分布（就是同样的值都聚集在连续的块中），那么就可以用数论分块加速计算，降低时间复杂度。

利用上述结论，我们先求出 $f(i)$ 的 **前缀和**（记作 $s(i)=\sum_{j=1}^i$ f(j)），然后每次以 $[l,r]=[l,\left\lfloor\dfrac n{\lfloor\frac ni\rfloor}\right\rfloor]$ 为一块，分块求出贡献累加到结果中即可。

伪代码如下：

$$
\begin{array}{ll}
1 & \text{获取 }f(i)\text{ 函数的前缀和，记为 }s(i).\\
2 & l\gets 1\\
3 & r\gets 0\\
4 & result\gets 0\\
5 & \textbf{while }l\leq n\textbf{ do}:\\
6 & \qquad r\gets\left\lfloor\dfrac n{\lfloor\frac nl\rfloor}\right\rfloor\\
7 & \qquad result\gets [s(r)-s(l-1)]\times\left\lfloor\dfrac nl\right\rfloor\\
8 & \qquad l\gets r+1\\
9 & \textbf{end while}\\
\end{array}
$$

最终得到的 $result$ 即为所求的和式。

## 例题
## 约数和
对于一个数 $X$，函数 $f(X)$ 表示 $X$ 所有约数的和。例如：$f(6)=1+2+3+6=12$。对于一个 $X$，Smart 可以很快的算出 $f(X)$。现在的问题是，给定两个正整数 $X,Y(X<Y)$，Smart 希望尽快地算出 $f(X)+f(X+1)+……+f(Y)$的值，你能帮助 Smart 算出这个值吗？
### 数据规模与约定
$1\leq X<Y\leq 2\times 10^9$。

- 一个数 1~n 中 i 作为约数出现了$\left\lfloor\dfrac ni\right\rfloor$次

```cpp
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll x,y,l,r,ans;
int main(){
	scanf("%lld%lld",&x,&y),--x;
	for(l=1;l<=x;l=r+1) r=x/(x/l),ans-=1ll*x/l*(r-l+1)*(l+r)/2;
	for(l=1;l<=y;l=r+1) r=y/(y/l),ans+=1ll*y/l*(r-l+1)*(l+r)/2;
	printf("%lld",ans);
	return 0;
}
```
## [CQOI2007]余数求和

给出正整数 $n$ 和 $k$，请计算

$$G(n, k) = \sum_{i = 1}^n k \bmod i$$

其中 $k\bmod i$ 表示 $k$ 除以 $i$ 的余数。
### 数据规模与约定
$1 \leq n, k \leq 10^9$。

![[Pasted image 20230926192405.png]]

```cpp
#include<bits/stdc++.h>
#define ll long long
using namespace std;
int n,k,l,r;
ll ans;
int main(){
	scanf("%d%d",&n,&k);
	ans=1ll*n*k; 
	for(l=1;l<=n;l=r+1){
		r=(k/l==0)?n:min(n,k/(k/l));
		ans-=1ll*k/l*(r-l+1)*(l+r)/2;
	}
	printf("%lld",ans);
	return 0;
}
```
## [P2260 [清华集训2012]模积和](https://www.luogu.com.cn/problem/P2260)
求

$$\sum_{i=1}^{n} \sum_{j=1}^{m} (n \bmod i) \times (m \bmod j), i \neq j \pmod{19940417}$$

### 数据规模与约定
$1 \leq n,m \leq 10^9$。

![[Pasted image 20230926192411.png]]

- **可借助上一题的方法求**

```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,m,nm,l,r,ansi,ansj,ans,a,b,mod=19940417,inv2=9970209,inv6=3323403;
long long sumf(long long x,long long y){
	return (y*(y+1)%mod*(2*y+1)%mod*inv6%mod+mod-x*(x+1)%mod*(2*x+1)%mod*inv6%mod)%mod;
}
long long read(){
    long long x=0,f=1;
    char ch=getchar();
    while(ch<'0'||ch>'9'){if(ch=='-') f=-1;ch=getchar();}
    while(ch>='0'&&ch<='9'){x=x*10+ch-'0',ch=getchar();}
    return x*f;
}
int main(){
	n=read();m=read();
	for(l=1;l<=n;l=r+1) r=n/(n/l),ansi+=(r-l+1)*(n/l)%mod*(l+r)%mod*inv2%mod,ansi%=mod;
	for(l=1;l<=m;l=r+1) r=m/(m/l),ansj+=(r-l+1)*(m/l)%mod*(l+r)%mod*inv2%mod,ansj%=mod;
	nm=min(n,m);
	for(l=1;l<=nm;l=r+1)
		r=min(n/(n/l),m/(m/l)),ans=(ans+((n/l)*(m/l)%mod*sumf(l-1,r)%mod)+mod-
		(r-l+1)*(l+r)%mod*inv2%mod*(m*(n/l)%mod+n*(m/l)%mod)%mod)%mod;
	printf("%lld",((n*n%mod+mod-ansi)%mod*((m*m%mod+mod-ansj)%mod)%mod+mod-(n*m%mod*nm%mod+ans)%mod)%mod);
	return 0;
}
```
