#数学 
## 龟速乘
由于数论这一part数都比较大，还要乘来乘去，经常会爆long long，可能需要龟速乘（一定要注意，不然拿几分随缘）。
```cpp
long long mul(long long a,long long b){
	sum=0;
	while(b){
		if(b&1) sum=(sum+a)%M;
		a=(a+a)%M,b>>=1;
	}
	return sum;
}
```

## __int128

使用除了要手写输入输出，其余一样。

范围能达到 -2^127-1 ~ 2^127-1。

```cpp
#include<bits/stdc++.h>
using namespace std;
__int128 a;
__int128 read(){
	__int128 x=0,f=1;
	char ch=getchar();
	while(ch<'0'||ch>'9'){if(ch=='-') f=-1;ch=getchar();}
	while(ch>='0'&&ch<='9'){x=x*10+ch-'0',ch=getchar();}
	return x*f;
}
void print(__int128 x){
	if(x<0) putchar('-'),x=-x;
	if(x>9) print(x/10);
	putchar(x%10+'0');
}
```
