#数学 
## 定义
欧拉函数，即 $\varphi(n)$，表示的是小于等于 $n$ 和 $n$ 互质的数的个数，如当 $n$ 是质数的时候，显然有 $\varphi(n) = n - 1$。

## 性质
-  若有 $\gcd(a, b) = 1$，则 $\varphi(a \times b) = \varphi(a) \times \varphi(b)$。特别地，当 $n$ 是奇数时 $\varphi(2n) = \varphi(n)$。
-   $n = \sum_{d \mid n}{\varphi(d)}$。
-   若 $n = p^k$，其中 $p$ 是质数，那么 $\varphi(n) = p^k - p^{k - 1}$。
-   由唯一分解定理，设 $n = \prod_{i=1}^{s}p_i^{k_i}$，其中 $p_i$ 是质数，有 $\varphi(n) = n \times \prod_{i = 1}^s{\dfrac{p_i - 1}{p_i}}$。
## 实现
### 单个数的欧拉函数
$\varphi(x)$：
```cpp
for(int i=2;i*i<=x;++i)if(x%i==0){
	p=p/i*(i-1);
	while(x%i==0) x/=i;
}
if(x>1) p=p/x*(x-1);
```
### 线性筛求欧拉函数
注意到在线性筛中，每一个合数都是被最小的质因子筛掉。设 $p_1$ 是 $n$ 的最小质因子，$n' = \frac{n}{p_1}$，那么线性筛的过程中 $n$ 通过 $n' \times p_1$ 筛掉。

如果 $n' \bmod p_1 = 0$，$n'$ 包含了 $n$ 的所有质因子。

$$
\begin{aligned}
\varphi(n) & = n \times \prod_{i = 1}^s{\frac{p_i - 1}{p_i}} \\\\
& = p_1 \times n' \times \prod_{i = 1}^s{\frac{p_i - 1}{p_i}} \\\\
& = p_1 \times \varphi(n')
\end{aligned}
$$

如果 $n' \bmod p_1 \neq 0$ ，$n'$ 和 $p_1$ 是互质：

$$
\begin{aligned}
\varphi(n) & = \varphi(p_1) \times \varphi(n') \\\\
& = (p_1 - 1) \times \varphi(n')
\end{aligned}
$$
```cpp
p[1]=1;
for(int i=2;i<=n;++i){
	if(!b[i]) s[++cnt]=i,p[i]=i-1;
	for(int j=1;j<=cnt&&1ll*i*s[j]<=n;++j){
		b[(t=i*s[j])]=1;
		if(i%s[j]) p[t]=p[i]*p[s[j]];
		else{p[t]=p[i]*s[j];break;}
	}
}
```
## 欧拉定理
若 $\gcd(a, m) = 1$，则 $a^{\varphi(m)} \equiv 1 \pmod{m}$。

当 $m$ 为质数时就是费马小定理。
## 扩展欧拉定理
$$
a^b\equiv
\begin{cases}
a^{b\bmod\varphi(p)},\,&\gcd(a,\,p)=1\\
a^b,&\gcd(a,\,p)\ne1,\,b<\varphi(p)\\
a^{b\bmod\varphi(p)+\varphi(p)},&\gcd(a,\,p)\ne1,\,b\ge\varphi(p)
\end{cases}
\pmod p
$$
## [P5091 【模板】扩展欧拉定理](https://www.luogu.com.cn/problem/P5091)
```cpp
#include<bits/stdc++.h>
using namespace std;
int a,x,m,p,b,fl;
char c;
int poww(int x,int y){
	int e=1;
	while(y){
		if(y&1) e=1ll*e*x%m;
		x=1ll*x*x%m,y>>=1;
	}
	return e;
}
int main(){
	scanf("%d%d",&a,&m),p=x=m;
	for(int i=2;i*i<=x;++i)if(x%i==0){
		p=p/i*(i-1);
		while(x%i==0) x/=i;
	}
	if(x>1) p=p/x*(x-1);
	c=getchar();
	while(c<'0'||c>'9') c=getchar();
	while('0'<=c&&c<='9'){
		b=b*10+c-'0',c=getchar();
		if(b>=p) b%=p,fl=1;  
	}
	printf("%d",poww(a,(b+p*fl)%m));
	return 0;
}
```
## [P2568 GCD](https://www.luogu.com.cn/problem/P2568)
若 $gcd(a,b)=1$，则 $gcd(a*p,b*p)=p,p\in\text{质数}$。

线性筛求出欧拉函数，枚举质数前缀和优化即可。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e7+5;
int n,cnt,s[N],t,b[N],p[N];
long long sum[N],ans;
int main(){
	scanf("%d",&n),sum[1]=p[1]=1;
	for(int i=2;i<=n;++i){
		if(!b[i]) s[++cnt]=i,p[i]=i-1;
		for(int j=1;j<=cnt&&1ll*i*s[j]<=n;++j){
			b[(t=i*s[j])]=1;
			if(i%s[j]) p[t]=p[i]*p[s[j]];
			else{p[t]=p[i]*s[j];break;}
		}
		sum[i]=sum[i-1]+p[i];
	}
	for(int i=1;i<=cnt;++i) ans+=2*sum[n/s[i]]-1;
	printf("%lld",ans);
	return 0;
}
```
