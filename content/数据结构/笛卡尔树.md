#数据结构 
## 简介
> 笛卡尔树是一种二叉树，每一个结点由一个键值二元组 $(v,p)$ 构成。要求 $v$ 满足二叉搜索树的性质，而 $p$ 满足堆的性质。如果笛卡尔树的 $v,p$ 键值确定，且 $v$ 互不相同，$p$ 互不相同，那么这个笛卡尔树的结构是唯一的。

Treap 本质上属于笛卡尔树，不过 $p$ 不是固定的，而是随机的。
## 例题
### [P5854 【模板】笛卡尔树](https://www.luogu.com.cn/problem/P5854)
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e7+5;
int n,p[N],ls[N],rs[N],t,lt,st[N];
long long l,r;
int read(){
	int x=0;char ch=getchar();
	while(ch<'0'||ch>'9') ch=getchar();
	while('0'<=ch&&ch<='9') x=x*10+ch-'0',ch=getchar();
	return x;
}
int main(){
	n=read();
	for(int i=1;i<=n;++i){
		p[i]=read(),lt=0;
		while(t&&p[st[t]]>p[i]) lt=st[t],--t;
		if(t) rs[st[t]]=i;
		ls[i]=lt,st[++t]=i;
	}
	for(int i=1;i<=n;++i) l^=1ll*i*(ls[i]+1),r^=1ll*i*(rs[i]+1);
	printf("%lld %lld",l,r); 
	return 0;
}
```
### [P1377 [TJOI2011] 树的序](https://www.luogu.com.cn/problem/P1377)
越后的元素在二叉搜索树中的位置越深。即对于每个 $x$ ，在它到根的路径上的元素一定在 $x$ 的前面。

因此，把插入顺序当作 $p$（保证儿子的 $p$ 大于父亲的 $p$），以 $x$ 作为 $v$（小的在左子树保证字典序最小）构建笛卡尔树，最后先序输出。
