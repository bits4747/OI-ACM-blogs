## [A. 人生的经验](http://www.nfls.com.cn:10611/contest/1045/problem/1)

**题意：**

求长度为 $l$，字符集大小为 $c(c\le26)$ 的 $c^l$ 个字符串的最短母串。

满足输出文件大小不超过 10MB。

**题解：**

这题和 [[ 10110. 「一本通 3.7 练习 4」太鼓达人](https //loj.ac/p/10110)](欧拉路径.md#[%2010110.%20「一本通%203.7%20练习%204」太鼓达人](https%20//loj.ac/p/10110)) 很类似。

可以发现每新增一个字母都可以利和前 $l-1$ 给字母组成未出现过的字符串，最短母串长度为 $l+c^l-1$。

将前 $l-1$ 的字符串作为点，每个点向外连 $c$ 条边，找欧拉回路即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e8;
char a[30];
int c,l,ans=1,p,x,b[N],t,q[N],tt,s[N];
int main(){
	scanf("%d%d%s",&c,&l,a);
	for(int i=1;i<=l;++i) ans=ans*c;
	p=ans/c,printf("%d\n",ans+l-1);
	if(l==1){
		for(int i=0;i<c;++i) putchar(a[i]);
		return 0;
	}
	for(int i=1;i<l;++i) putchar(a[0]);
	do{
		x=q[t];
		if(b[x]<c)
			q[++t]=x*c%p+b[x],++b[x];
		else s[++tt]=q[t]%c,--t;
	}while(t);
	for(int i=tt;i;--i) putchar(a[s[i]]);
	return 0;
}
```

## [B. 矩阵](http://www.nfls.com.cn:10611/contest/1045/problem/2)
原题：[#6030. 「雅礼集训 2017 Day1」矩阵](https://loj.ac/p/6030)

**题意：**

有一个 $n \times n,n\le1000$ 的矩阵，每个位置 $(i, j)$ 如果是 `.` 表示为白色，如果是 `#` 表示为黑色。

现在有一种操作，选择两个整数 $i, j \in [1, n]$ ，记 $(i, 1), (i, 2), \ldots, (i, n)$ 的颜色为 $C_1, C_2, \ldots C_n$，将 $(1, j), (2, j), \ldots, (n, j)$ 的颜色赋为 $C_1, C_2, \ldots, C_n$。

输出最少步数，否则输出 $-1$。

**题解：**

考虑先将一行变为全黑，再 $n$ 次把所有列染黑。

将第 $i$ 行染黑的条件第 $i$ 列存在黑色（记 $a_{k,i}$ 为黑），当 $a_{i,j}$ 为白时对 $(k,j)$ 操作即可，代价为 $\sum|a_{i,j}\ \text{为白}|$。

若第 $i$ 列不存在黑色则要额外花费一次操作将第 $i$ 列其中一点染黑，因此当且仅当全图没有黑色时无解。

我们贪心枚举每一行全染黑的最小花费即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1005;
char c[N][N];
int n,a[N],b[N],sum,ans=1e9,fl;
int main(){
	scanf("%d",&n);
	for(int i=1;i<=n;++i)
		for(int j=1;j<=n;++j){
			scanf(" %c",&c[i][j]);
			if(c[i][j]=='#') ++a[i],++b[j],fl=1;
		}
	for(int i=1;i<=n;++i) ans=min(ans,n-a[i]+!b[i]);
	if(!fl) return printf("-1"),0;
	printf("%d",ans+n);
	return 0;
}
```
## [C. Divide](http://www.nfls.com.cn:10611/contest/1045/problem/3)
**题意：**

一个舰队有 $n$ 艘飞船，每艘飞船有一个武力值 $w_i$，现需要把飞船分成两队。对于任意两艘不在同一队的武力值之和不小于 $m$ 的飞船配合默契，求最多能有多少对飞船配合默契及分配方案数（对 $1e9+7$ 取模）。

$n\le2000,w_i\le1e6,m\le2e6$

**题解：**

我们将 $w_i$ 排序。

注意到若 $w_1+w_n<m$，则 $w_1$ 无效，将其删去变为子问题 $[2,n]$；相反，则 $w_n$ 可以与 $[1,n-1]$ 契合，将其删去。

我们将删去的数放入队列，发现队列里的数要么和后面的数都不契合，要么都契合，我们用 $q_i=0/1$ 表示是否能契合。我们将队列翻转后 dp，定义 $f_{i,j}$ 表示反转后队列前 $i$ 个数 $j$ 个在 $A$ 组的最大契合度，则 $$f_{i,j}=\max(f_{i-1,j}+q_i\times j,f_{i-1,j-1}\times(i-j))$$

方案数转移时顺便求求。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2005,p=1e9+7;
int n,m,w[N],t,q[N],g[N][N],sum;
long long s1,s2,f[N][N],ans;
int main(){
	scanf("%d%d",&n,&m);
	for(int i=1;i<=n;++i) scanf("%d",&w[i]);
	sort(w+1,w+1+n);
	for(int l=1,r=n;l<=r;){
		if(w[l]+w[r]<m) ++t,++l;
		else q[++t]=1,--r;
	}
	reverse(q+1,q+1+n),g[0][0]=1;
	for(int i=1;i<=n;++i){
		g[i][0]=g[i][i]=1;
		for(int j=1;j<i;++j){
			s1=f[i-1][j]+q[i]*j,s2=f[i-1][j-1]+q[i]*(i-j);
			if(s1==s2) f[i][j]=s1,g[i][j]=(g[i-1][j]+g[i-1][j-1])%p;
			if(s1>s2) f[i][j]=s1,g[i][j]=g[i-1][j];
			if(s1<s2) f[i][j]=s2,g[i][j]=g[i-1][j-1];
		}
	}
	for(int i=0;i<=n;++i){
		if(f[n][i]==ans) sum=(sum+g[n][i])%p;
		if(f[n][i]>ans) ans=f[n][i],sum=g[n][i];
	}
	printf("%lld %d",ans,sum);
	return 0;
}
```
## [D. Hby的旅游之都](http://www.nfls.com.cn:10611/contest/1045/problem/4)
**题意：**

给定一个 $n\le50000$ 个点 $m\le200000$ 条的有向无环图，要求给每条边上 `R`、`G`、`B` 三种颜色使得不存在任意一条路径有连续 $42$ 条相同颜色的边。

**题解：**

因为 $42^3>50000$，我们先把点分为 $42$ 组，组与组之间的连边为 $R$（则最多连续走 $41$ 条同色边）；每组内再分 $42$ 组，两组间连边为 $G$；剩下同组的点间连边为 $B$。

**注意：要在拓扑排序后分组。**

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=5e4+5,M=2e5+5,R=42*42,G=42;
int n,m,x[M],y[M],d[N],t,id[N],u;
vector<int>e[N];
queue<int>q;
int main(){
	freopen("travel.in","r",stdin);
	freopen("travel.out","w",stdout);
	scanf("%d%d",&n,&m);
	for(int i=1;i<=m;++i) scanf("%d%d",&x[i],&y[i]),++d[y[i]],e[x[i]].push_back(y[i]);
	for(int i=1;i<=n;++i)if(!d[i]) id[i]=++t,q.push(i);
	while(!q.empty()){
		u=q.front(),q.pop();
		for(int v:e[u])if(!(--d[v])) id[v]=++t,q.push(v); 
	}
	for(int i=1;i<=m;++i){
		if(id[x[i]]/R!=id[y[i]]/R) printf("R\n");
		else if(id[x[i]]/G!=id[y[i]]/G) printf("G\n");
		else printf("B\n");
	}
	return 0;
}
```

## [E. 单调上升序列](http://www.nfls.com.cn:10611/contest/1045/problem/5)
原题：[P5419 [CTSC2016] 单调上升序列](https://www.luogu.com.cn/problem/P5419)

**题意：**

构造一个边权不同的 $n(n\le500,n\%2=0)$ 阶完全图，使得其最大上升路径长度最小。

**题解：**

题目给出了结论：

> 结论：
> 
> 假设带权无向图 $G$ 有 $100$ 个节点 $1000$ 条边，且所有权值各不相同。那么，$G$ 中一定存在一个单调上升路径，它的长度大于等于 $20$。
> 
> 证明：
> 
> 假设每个节点上有一个探险家。我们按权值从小到大枚举所有的边，每次将该边连接的节点中的探险家的位置进行对调。可以知道，每个探险家都走的是一条单调上升路径。另外，由于共有 $100$ 个探险家，而探险家一共走了 $2000$ 步，所以有人走了 $20$ 步。证毕。

因此，我们只需考虑如何使 $n$ 阶完全图的最大上升路径长度为 $n-1$。

如果两个相邻的数不在相邻边上，则它们最多有一个位于同一条单调上升路径上。因此，我们可以把边分成 $n-1$ 个大小为 $\frac n2$ 的边不相交的集合，每个集合标上连续的 $\frac n2$ 个数即可。

划分方法如下：

选定一个特殊点，枚举剩下 $n-1$ 个点与其相连，其余 $n-2$ 个点对称相连。

![](Pasted%20image%2020231101105646.gif)

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=505;
int n,x,y,a[N][N]; 
int main(){
	scanf("%d",&n);
	for(int i=1;i<n;++i){
		x=y=i,a[i][n]=i*n/2;
		for(int j=n/2-1;j;--j){
			--x,++y;
			if(!x) x=n-1;
			if(y==n) y=1;
			a[x][y]=(i-1)*n/2+j;
		}
	}
	for(int i=1;i<=n;++i){
		for(int j=i+1;j<=n;++j) printf("%d ",(a[i][j]?a[i][j]:a[j][i]));
		printf("\n");
	}
	return 0;
}
```

## [F. 皇后平板](http://www.nfls.com.cn:10611/contest/1045/problem/6)
**题意：**

要求构造一个 $n\times n,n\le1500$ 的矩阵，使得任意 $(x,y)$ 都有第 $x$ 列与第 $y$ 行的所有数为 $1\dots2n-1$ 的全集。

**题解：**

手糊发现奇数除了 $1$ 都不行。

对于偶数，主对角线上的数相同，我们填 $n$。

由对称性知，剩下 $n(n-1)$ 个格子和 $2n-2$ 个数，每个数要填 $\frac n2$ 个格子，且这些格子行列不同（一个数填 $(x_1,y_1)\dots(x_{\frac n2},y_{\frac n2})$，对于 $i\ne j,x_i\ne j\ 且\ y_i\ne y_j$）。

感觉和上一题有异曲同工之妙，我们把 $n$ 个点的完全图划分为 $n-1$ 个大小为 $\frac n2$ 的匹配，第 $i$ 个图中的匹配边 $x,y(x<y)$ 对应 $(x,y)$ 填 $i$，$(y,x)$ 填 $i+n$。 

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1505;
int n,x,y,a[N][N];
int main(){
	freopen("hhpb.in","r",stdin);
	freopen("hhpb.out","w",stdout);
	scanf("%d",&n);
	if(n==1) printf("2\n1"),exit(0);
	if(n&1) printf("1\nNO"),exit(0);
	printf("2\n");
	for(int i=1;i<=n;++i) a[i][i]=n;
	for(int i=1;i<n;++i){
		x=y=i,a[i][n]=i,a[n][i]=i+n;
		for(int j=n/2-1;j;--j){
			--x,++y;
			if(!x) x=n-1;
			if(y==n) y=1;
			a[min(x,y)][max(x,y)]=i,a[max(x,y)][min(x,y)]=i+n;
		}
	}
	for(int i=1;i<=n;++i){
		for(int j=1;j<=n;++j) printf("%d ",a[i][j]);
		printf("\n");
	}
	return 0;
}
```
