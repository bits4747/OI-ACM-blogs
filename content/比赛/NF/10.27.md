## [A. 完美主义](http://www.nfls.com.cn:10611/contest/1035/problem/1)
**题意：**

![](Pasted%20image%2020231106143025.png)
![](Pasted%20image%2020231106143048.png)

**题解：**

当前长度为 $x$，有以下几种操作：

1. $x\stackrel{1}\longrightarrow x+1$。
2. $x\stackrel{1}\longrightarrow x-1$。
3. $x\stackrel{3}\longrightarrow 0$。
4. $x\stackrel{2k+2}\longrightarrow k\times x,k>1$。

建边跑最短路即可，4 有 $\ln n$ 条边。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=6e5+5;
int n,a,b,d[N];
struct qwq{
	int x,d;
	bool operator <(const qwq b)const{return d>b.d;}
}u;
priority_queue<qwq>q;
int main(){
	freopen("perfect.in","r",stdin);
	freopen("perfect.out","w",stdout);
	scanf("%d%d",&a,&b),memset(d,127,sizeof(d)),q.push((qwq){a,d[a]=0}),n=b<<1;
	if(a>3) q.push((qwq){0,d[0]=3});
	while(!q.empty()){
		u=q.top(),q.pop();
		if(u.d^d[u.x]) continue;
		if(u.x>0&&d[u.x-1]>u.d+1) q.push((qwq){u.x-1,d[u.x-1]=u.d+1});
		if(u.x<n&&d[u.x+1]>u.d+1) q.push((qwq){u.x+1,d[u.x+1]=u.d+1});
		if(u.x>2) for(int i=2;i*u.x<=n;++i)if(d[i*u.x]>u.d+2*i+2)
			q.push((qwq){i*u.x,d[i*u.x]=u.d+2*i+2});
	}
	printf("%d",d[b]);
	return 0;
}
```

## [B. 挑战哈密顿](http://www.nfls.com.cn:10611/contest/1035/problem/2)
**题意：**

给定一个 $n\ (n\le2000)$ 个点的完全无向图，每条边染红色或蓝色。对于每个点 $u$ 求一条最短的以 $u$ 为起点、经过每个点至少一次、按顺序经过的边的颜色交替至多一次的路径。

**题解：**

首先路径长度最短为 $n$，我们考虑能否构造出这样的路径。

我们依次把 $u+0\dots n-1$ 加入链表 $q$，若能一路同色，则可构造长为 $n$ 的合法路径。

否则，我们记分界点为 $k$（即出现 $(k-1,k)$ 与 $(k,k+1)$ 异色，$\pm1$ 取模）。

之后加入点 $p$：
- 若 $(p,k)=(k,k+1)$，把 $p$ 插到 $k$ 前面；若 $(k-1,p)=(p,k)$ 更新分界点 $k=k-1$（若 $k-1$ 为链首变为单色路径），否则更新分界点 $k=p$。
- 若 $(p,k)=(k-1,k)$，把 $p$ 插到 $k$ 后面；若 $(k,p)=(p,k+1)$ 更新分界点 $k=k+1$（若 $k-1$ 为链尾变为单色路径），否则更新分界点 $k=p$。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2005;
char c;
int n,a[N][N],p,la,b;
list<int>q;
list<int>::iterator it;
void work(int x){
	printf("%d\n",n),q.clear(),q.push_back(x),b=0;
	for(int i=1;i<n;++i){
		p=(i+x-1)%n+1;
		if(!b){
			if(!(q.size()==1||a[q.back()][p]==la)) b=1,it=q.end(),--it;
			la=a[q.back()][p],q.push_back(p);continue;
		}
		if(a[p][*it]==la){
			it=q.insert(it,p),--it;
			if(a[*it][p]^la) ++it;
			else if(it==q.begin()) b=0;
		}
		else{
			++it,q.insert(it,p);
			if(a[*it][p]==la) --it;
			else if(it==(--q.end())) b=0,la^=1;
		}
	}
	for(int i:q) printf("%d ",i);
	printf("\n");
}
int main(){
	freopen("hamil.in","r",stdin);
	freopen("hamil.out","w",stdout);
	scanf("%d",&n);
	for(int i=2;i<=n;++i)for(int j=1;j<i;++j)scanf(" %c",&c),a[i][j]=a[j][i]=(c=='R');
	for(int i=1;i<=n;++i) work(i);
	return 0;
}
```
## [C. 装备](http://www.nfls.com.cn:10611/contest/1035/problem/3)
**题意：**

$n$ 个装备，权值为 $c_i$，$m$ 个装备栏，每个装备栏当前使用装备 $a_i$（保证 $a_i$ 互不相同），候选装备 $b_i$。 

切换一次装备指把一个装备栏的 $a_i,b_i$ 互换，且满足换完后 $a_i$ 互不相同。

战斗力为 $\sum_{i=1}^{m} c_{a_i}\times n^i$，求最多切换 $k$ 次装备可达到的最大战斗力。

**题解：**

显然从后往前确定装备。

我们连边 $a_i\to b_i$，可以切换装备栏 $i$ 当且仅当 $a_i$ 往后无环且走到叶子的距离不超过剩下的 $k$，操作后从 $b_i$ 到叶子的状态皆已确定。

具体实现上，我们建反图，即连边 $b_i\to a_i$，将原图叶子入队 dfs（解决无环），划分为若干个互不影响的连通块。

考虑装备栏 $i$，若 $a_i$ 状态还未确定则操作：
1. 切换更优：判断 $k$ 是否够 $a_i$ 走到根，够用则把 $a_i$ 所在连通块的根变为 $a_i$。（$b_i$ 到根状态确定）
2. 切换不优：标记 $a_i$ 及其子树。（这些点因为 $a_i$ 状态确定无法走到根）

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5;
int n,m,k,v,c[N],a[N],b[N],p[N],in[N],t,rt[N],co[N],d[N],tim,dfn[N],sz[N],x,RT,vis[N],t1,st[N],t2,ans[N];
vector<int>e[N];
void dfs(int u){
	co[u]=t,d[u]=d[b[p[u]]]+1,dfn[u]=++tim,sz[u]=1;
	for(int v:e[u]) dfs(v),sz[u]+=sz[v];
}
void upd(int u){
	if(vis[u]) return;
	vis[u]=1;
	for(int v:e[u]) upd(v);
}
int chk(int x,int y){return dfn[x]<=dfn[y]&&dfn[y]<dfn[x]+sz[x];}
int main(){
	freopen("equipment.in","r",stdin);
	freopen("equipment.out","w",stdout);
	scanf("%d%d%d",&n,&m,&k);
	for(int i=1;i<=n;++i) scanf("%d",&c[i]);
	for(int i=1;i<=m;++i) scanf("%d%d",&a[i],&b[i]),e[b[i]].push_back(a[i]),p[a[i]]=i,in[a[i]]=1;
	for(int i=1;i<=n;++i)if(!in[i]) rt[++t]=i,dfs(i);
	for(int i=m;i;--i){
		x=a[i],RT=rt[co[x]];
		if(!vis[x]&&chk(RT,x)){
			if(c[x]<c[b[i]]){
				if(d[x]-d[RT]<=k){
					k-=d[x]-d[RT];
					while(x^RT) st[++t1]=p[x],x=b[p[x]];
					while(t1) ans[++t2]=st[t1--];
					rt[co[a[i]]]=a[i];
				}	
			}
			else if(c[x]>c[b[i]]) upd(a[i]);
		}
	}
	printf("%d\n",t2);
	for(int i=1;i<=t2;++i) printf("%d\n",ans[i]);
	return 0;
}
```
