## [A. 你还没有卸载吗](http://www.nfls.com.cn:10611/contest/1060/problem/1)
![](Pasted%20image%2020231110125849.png)

```cpp
#include<bits/stdc++.h>
using namespace std;
int t,a1,b1,a2,b2,n,res,l,r,L,R,ans;
void work(){
	scanf("%d%d%d%d%d",&a1,&b1,&a2,&b2,&n),ans=0;
	for(l=1;l<=n;l=r+1){
		r=a1/l?min(n,a1/(a1/l)):n,res=b1+a1/l-b2;
		if(res<0) continue;
		if(!res) L=a2+1,R=n;
		else L=a2/(res+1)+1,R=min(n,a2/res);
		ans+=max(0,min(r,R)-max(l,L)+1);
	}
	printf("%d\n",ans);
} 
int main(){
	freopen("game.in","r",stdin);
	freopen("game.out","w",stdout);
	scanf("%d",&t);
	while(t--) work();
	return 0;
}
```
## [B. 仪式感](http://www.nfls.com.cn:10611/contest/1060/problem/2)
**题意：**

给定集合 $A$，对于 $\forall k\in[1, m]$，分别求出最少/最多能从 $A$ 中取出多少个数，使它们的 $gcd = k$。

$|A|,A_i,m\le3e5$

**题解：**

对于每个 $k$ 分别处理其倍数集合 $S$（合并 $A$ 中相同的数，总共要处理的个数是 $n\ln n$ 级别的）。

若 $\gcd S=1$，最多能选 $|S|$，现在考虑最小值。

因为 $2*3*5*7*11*13*17>3e5$，答案上界为 $7$。

![](Pasted%20image%2020231110165756.png)
![](Pasted%20image%2020231110165830.png)

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=3e5+5;
int n,m,x,mx,a[N],s[N],mn[N];
__int128 c[N][8],f[N];
int main(){
	freopen("sor.in","r",stdin);
	freopen("sor.out","w",stdout);
	scanf("%d%d",&n,&m);
	for(int i=1;i<=n;++i) scanf("%d",&x),mx=max(mx,x),++a[x];
	for(int i=1;i<=mx;++i)for(int j=i;j<=mx;j+=i) s[i]+=a[j];
	for(int i=0;i<=n;++i) c[i][0]=1;
	for(int i=1;i<=n;++i)for(int j=1;j<=7;++j) c[i][j]=c[i-1][j-1]+c[i-1][j];
	for(int i=7;i;--i)for(int j=mx;j;--j){
		f[j]=c[s[j]][i];
		for(int k=j+j;k<=mx;k+=j) f[j]-=f[k];
		if(f[j]) mn[j]=i;
	}
	for(int i=1;i<=m;++i)
		if(!mn[i]) printf("-1 -1\n");
		else printf("%d %d\n",mn[i],s[i]);
	return 0;
}
```
