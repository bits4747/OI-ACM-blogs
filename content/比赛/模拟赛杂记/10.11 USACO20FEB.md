## [[USACO20FEB] Clock Tree S](https://www.luogu.com.cn/problem/P6150)★

> 很妙的思维题

我们钦定一点 $u$ 为根，来判断是否可行。

可以发现，我们可以一直走到叶子，通过在父子节点间来回横跳至儿子为 $12$，再不断往上。若确定完 $u$ 的所有儿子后 $u$ 恰好为 $12$ 或 $1$（最后一个儿子只下去不上来），则可行。

复杂度 $O(n^2)$。

再仔细观察可以发现，我们将树黑白染色后，走任意一条边都使黑点、白点的权值各 $+1$，黑白点的差是固定的。因此，若点 $u$ 为根合法，当且仅当 $u\ \text{颜色的权值和}-u\ \text{另一颜色的权值和}\equiv0/1\pmod {12}$。

复杂度 $O(n)$。

## [[USACO20FEB] Delegation G](https://www.luogu.com.cn/problem/P6147)
**题意：**

给定 $N$（$1 \leq N \leq 10^5$）个点的树，求所有正整数 $K$，使得整棵树被划分成若干条链，且每条链的长度都是 $K$。

**题解：**

我们考虑如何判断能否将树划分为长度为 $K$ 的链。

首先，若 $K$ 不为 $N-1$ 的因子，肯定不行。

对于一点 $u$，最多只有一条链能往上。因此，若一点 $u$ 所有链不能完全匹配或只剩一条，则无解。

把点 $u$ 的所有子链放入桶里搞一搞，判断一次 $K$ 复杂度 $O(N)$。

由于一个数的因数是 $\sqrt N$ 级别的，复杂度为 $O(N\sqrt N)$。

## [[USACO20FEB] Delegation P](https://www.luogu.com.cn/problem/P6142)
**题意：**

给定 $N$（$1 \leq N \leq 10^5$）个点的树，求最大的正整数 $K$，使得整棵树被划分成若干条链，且每条链的长度都 **至少** 是 $K$。

**题解：**

思路和上一题相似，我们二分 $K$。

check 时每个点在保证能匹配的前提下尽量上转最大的子链（子链数量为奇数就补个 $0$）。

实现上给每个点开个 multiset，总复杂度 $O(N\log^2N)$。

## [[USACO20FEB] Help Yourself P](https://www.luogu.com.cn/problem/P6144)★
**题意：**

在一个数轴上有 $N$ 条线段，第 $i$ 条线段覆盖了从 $l_i$ 到 $r_i$ 的所有实数（包含 $l_i$ 和 $r_i$）。

定义若干条线段的**并**为一个包含了所有被至少一个线段覆盖的点的集合。

定义若干条线段的**复杂度**为这些线段的并形成的连通块的数目的 $K$ 次方。

求出给定 $N$ 条线段的所有子集（共有 $2^N$ 个）的复杂度之和对 $10^9+7$ 取模的结果。

$1 \leq N \leq 10^5$。$2 \leq K \leq 10$，任意两个端点都不在同一位置上。

**题解：**

我们考虑 $K=1$ 的情况，即 [[USACO20FEB] Help Yourself G](https://www.luogu.com.cn/problem/P6146)。

所有线段按左端点排序，定义 $f_i$ 为最右的右端点为 $i$ 的所有子集的复杂度之和。

新增一条线段 $[l,r]$，则 $f_r+=\sum_{i=l}^rf_i+\sum_{j=0}^{l-1}(f_j+1)$；同时所有 $f_{r+1\sim 2*n}\times2$，因为都包含了 $[l,r]$，当前线段可选可不选。

当 $K\ne1$ 时，可以维护 $1\sim K$ 的权值和，$(x+1)^K$ 可以通过二项式定理求出，$(x+1)^K=\sum_{i=0}^K​C_K^i​x^i$。

因此，用线段树维护区间 $\times 2$、区间和即可。

复杂度 $O(K^2N\log N)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define fi first
#define se second
#define ls k<<1
#define rs k<<1|1
#define pii pair<int,int>
const int N=1e5+5,P=1e9+7;
pii a[N];
int n,k,m,c[11][11],p[N<<3];
struct qwq{
	int x[11];
	qwq operator +(qwq b){qwq t;for(int i=0;i<=k;++i)t.x[i]=(x[i]+b.x[i])%P;return t;}
	qwq operator *(int b){qwq t;for(int i=0;i<=k;++i)t.x[i]=1ll*x[i]*b%P;return t;}
}s[N<<3],f,g;
void pd(int k){
	if(p[k]==1) return;
	s[ls]=s[ls]*p[k],s[rs]=s[rs]*p[k],p[ls]=1ll*p[ls]*p[k]%P,p[rs]=1ll*p[rs]*p[k]%P,p[k]=1;
}
void add(int k,int l,int r,int x){
	if(l==r){s[k]=f;return;}
	int mi=(l+r)>>1;pd(k);
	if(x<=mi) add(ls,l,mi,x);
	else add(rs,mi+1,r,x);
	s[k]=s[ls]+s[rs];
}
qwq ask(int k,int l,int r,int x,int y){
	if(x<=l&&r<=y) return s[k];
	int mi=(l+r)>>1;pd(k);
	if(x<=mi&&y>mi) return ask(ls,l,mi,x,y)+ask(rs,mi+1,r,x,y);
	if(x<=mi) return ask(ls,l,mi,x,y);
	return ask(rs,mi+1,r,x,y);
}
void mul(int k,int l,int r,int x,int y){
	if(x<=l&&r<=y){(p[k]<<=1)%=P,s[k]=s[k]*2;return;}
	int mi=(l+r)>>1;pd(k);
	if(x<=mi) mul(ls,l,mi,x,y);
	if(y>mi) mul(rs,mi+1,r,x,y);
	s[k]=s[ls]+s[rs];
}
int main(){
	scanf("%d%d",&n,&k),m=2*n;
	for(int i=0;i<=k;++i) c[i][0]=1;
	for(int i=1;i<=k;++i)for(int j=1;j<=i;++j) c[i][j]=c[i-1][j]+c[i-1][j-1];
	for(int i=1;i<=n;++i) scanf("%d%d",&a[i].fi,&a[i].se);
	sort(a+1,a+1+n),memset(p,1,sizeof(p)),f.x[0]=1,add(1,0,m,0);
	for(int i=1;i<=n;++i){
		g=ask(1,0,m,0,a[i].fi-1),memset(f.x,0,sizeof(f.x));
		for(int i=0;i<=k;++i)for(int j=0;j<=i;++j) (f.x[i]+=1ll*c[i][j]*g.x[j]%P)%=P;
		g=ask(1,0,m,a[i].fi,a[i].se);
		for(int i=0;i<=k;++i) (f.x[i]+=g.x[i])%=P;
		add(1,0,m,a[i].se);
		if(a[i].se<m) mul(1,0,m,a[i].se+1,m);
	}
	printf("%d",ask(1,0,m,0,m).x[k]);
	return 0;
}
```
