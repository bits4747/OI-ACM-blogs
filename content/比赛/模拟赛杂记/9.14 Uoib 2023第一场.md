## [P9290 [ROI 2018] Decryption](https://www.luogu.com.cn/problem/P9290)
![[Pasted image 20230918131031.png]]

**题解：**

定义 $f_i$ 为以 $i$ 结尾时的最小划分次数。

维护两个栈，一个单调递增的栈 $q1$，一个**严格**单调递减的栈 $q2$。

**严格**单调递减的栈中 $i$ 前面的肯定大于 $i$，与 $i$ 不在同一个划分中，在 $q1$ 中找到下标大于 $q2[t2-1]$ 的就是 $i$ 所在划分段的开头。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=3e5+5;
int n,a[N],t1,q1[N],t2,q2[N],f[N];
int main(){
	scanf("%d",&n);
	for(int i=1;i<=n;++i){
		scanf("%d",&a[i]);
		while(t1&&a[q1[t1]]>a[i]) --t1;
		q1[++t1]=i;
		while(t2&&a[q2[t2]]<=a[i]) --t2;
		q2[++t2]=i;
		f[i]=f[q1[upper_bound(q1+1,q1+1+t1,q2[t2-1])-q1]-1]+1;
	}
	printf("%d",f[n]);
	return 0;
}
```
## [P7169 [eJOI2020 Day1] Exam](https://www.luogu.com.cn/problem/P7169)
**题意：**

给定一个长度为 $N$ 的序列 $A_i$，你可以进行无数次下面这个操作：

- 选定一个大小不小于 $2$ 的区间，这个区间里的数等于这个区间里的最大值。

你需要用这些操作使得 $A_i=B_i$，求最多能使得多少数满足要求。

- $2 \le N$，$1 \le A_i,B_i \le 10^9$

**题解：**

先预处理出 $b_i$ 可在 $a_i$ 向外拓展的最远距离 $L_i,R_i$。（相等时视作不能拓展）

例如，当 $a_i=b_j,i<j$ 时，要使 $b_j$ 有贡献则需 $[i,j]$ 内没有障碍。

令 $f_{i,j}$ 为处理到 $b_i$，$a$ 涉及到的点编号最大的为 $j$，可以达成的贡献。则 $f_{i,Li}​=\max​\{f_{i−1,j}\}+1,j\le L_i$，$f_{i,Ri}​=\max​\{f_{i−1,j}\}+1,j\le R_i$。可用树状数组维护。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5;
#define mp make_pair
#define pa pair<int,int>
#define fi first
#define se second
int n,x,l[N],r[N],a[N],ll,rr;
pa s[N*2];
set<pa>q;
set<pa>::iterator it;
void add(int k,int v){for(;k<=n;k+=k&-k) a[k]=max(a[k],v);}
int ask(int k){int re=0;for(;k;k-=k&-k) re=max(re,a[k]);return re;}
int main(){
	scanf("%d",&n);
	for(int i=1;i<=n;++i) scanf("%d",&x),s[i]=mp(-x,-i);
	for(int i=1;i<=n;++i) scanf("%d",&x),s[i+n]=mp(-x,i);
	sort(s+1,s+1+n+n);
	for(int i=1;i<=n+n;++i){
		if(s[i].se<0) q.insert(mp(-s[i].se,-s[i].fi));
		else{
			it=q.lower_bound(mp(s[i].se,0));
			if(it!=q.end()&&(*it).se==-s[i].fi) r[s[i].se]=(*it).fi;
			if(it!=q.end()&&(*it).fi==s[i].se) ++it;
			if(it!=q.begin()&&(*(--it)).se==-s[i].fi) l[s[i].se]=(*it).fi;
		}
	}
	for(int i=1;i<=n;++i){
		ll=ask(l[i]),rr=ask(r[i]);
		if(l[i]) add(l[i],ll+1);
		if(r[i]) add(r[i],rr+1);
	}
	printf("%d",ask(n));
	return 0;
}
```
## [P9292 [ROI 2018] Robomarathon](https://www.luogu.com.cn/problem/P9292)
**题意：**

有 $N$ 名选手，每位选手占据一条分道，已知 $i$ 号跑完全程需要 $a_i$ 秒，每条跑道上的喇叭有开有关，声音传播速度为 $1$ 道每秒，选手一听到发令就立即起跑。请求出每位选手的最好名次或最差名次。

$1 \leq n \leq 4 \times 10^5$，$0\leq a_i \leq 10^9$

**题解：**

首先，要使一个人名次最好就只开其跑道的喇叭。

考虑要使一个人 $i$ 名次最差的情况，我们的目标是让他最晚听到发令声。经过思考，只有两种情况：

1. 最左边发令。当 $i$ 到 $1$ 的距离比 $i$ 到 $n$ 的距离小时，$1$ 关于 $i$ 的对称点到 $n$ 也第一时间发令起跑。（不影响 $i$ 听到的时间，并提前了部分人的出发时间）
2. 最右边发令。当 $i$ 到 $n$ 的距离比 $i$ 到 $1$ 的距离小时，$n$ 关于 $i$ 的对称点到 $1$ 也第一时间发令起跑。

策略明了，关键在于如何优雅地实现。由于 $n \leq 4 \times 10^5$，我们不能对每个选手分别计算，要算一起算。

我们可以根据坐标对 $a_i$ 进行加减，使之满足延迟出发的相对时间，再用树状数组维护小于 $a_i$ 的人数。

自行思考，具体见代码。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=8e5+5;
int n,nn,p,a[N],m,c[N],r,x,f[N],g[N],ans[N],s[N];
void cle(){for(int i=1;i<=m;++i) s[i]=0;}
void add(int k,int v){for(;k<=m;k+=k&-k) s[k]+=v;}
int ask(int k){int re=0;for(;k;k-=k&-k) re+=s[k];return re;}
#define L(k) lower_bound(c+1,c+1+m,(k))-c
void work1(){
	for(int i=1;i<=n;++i) c[i]=a[i]-i;
	sort(c+1,c+1+n),m=unique(c+1,c+1+n)-c-1;
	for(int i=1;i<=n;++i) x=L(a[i]-i),f[i]+=ask(x-1),add(x,1);
	cle();
	for(int i=1;i<=n;++i) c[i]=a[i]+i;
	sort(c+1,c+1+n),m=unique(c+1,c+1+n)-c-1;
	for(int i=n;i;--i) x=L(a[i]+i),f[i]+=ask(x-1),add(x,1);
	for(int i=1;i<=n;++i) printf("%d\n",f[i]+1);
}
void work2(){
	for(int i=1;i<=n;++i) c[i]=a[i]+i;
	sort(c+1,c+1+n),m=unique(c+1,c+1+n)-c-1;
	for(int i=1;i<=n;++i) x=L(a[i]+i),f[i]+=ask(x-1),add(x,1);
	cle();
	for(int i=n;i>nn;--i) x=L(a[i]+i),f[i]+=ask(x-1),add(x,1);
	cle();
	for(int i=1;i<=n;++i) c[i]=a[i];
	sort(c+1,c+1+n),m=unique(c+1,c+1+n)-c-1,r=n;
	for(int i=nn;i;--i){
		while(i-1<r-i) add(L(a[r]),1),--r;
		f[i]+=ask(L(a[i]+i-1)-1);
	}
	cle();
	for(int i=1;i<=n;++i) c[i]=a[i]-i;
	sort(c+1,c+1+n),m=unique(c+1,c+1+n)-c-1,r=0;
	for(int i=1;i<=nn;++i){
		while(r<i+i-1) ++r,add(L(a[r]-r),1);
		add(L(a[i]-i),-1),f[i]+=ask(L(a[i]-i)-1);
	}
	cle();
}
int main(){
	scanf("%d%d",&n,&p);f[0]=-1;
	for(int i=1;i<=n;++i) scanf("%d",&a[i]);
	if(p==1) work1(),exit(0);
	nn=(n+1)/2,work2();
	for(int i=1;i<=n;++i) swap(f[i],g[i]);
	for(int i=1;i<=nn;++i) swap(a[i],a[n-i+1]);
	work2();
	for(int i=1;i<=n;++i) printf("%d\n",max(f[n-i+1],g[i])+1);
	return 0;
}
```
## [P9289 [ROI 2018] Quantum teleportation](https://www.luogu.com.cn/problem/P9289)
**题意：** 在 $N×M$ 的网格上给定 $K$ 个点，定义两点间的距离为$2^{max(|x_i−x_j|,|y_i−y_j|)}$，$N,M,K≤10^4$，求 $1$ 到 $k$ 的最短路。

**题解：**

可以发现，每条带上的点到 $A$ 的距离相等，可以线段树优化建图。

![[Pasted image 20230918141405.png]]

我们把每一行每一列都建一棵线段树辅助建图。再暴力求出每个点周围九块中里其最近的点，得到最近距离，在带上线段树优化建图。

![[Pasted image 20230918141740.png]]

建完图后跑最短路即可。

由于两点间距离为 $2^{max(|x_i−x_j|,|y_i−y_j|)}$，需要手写 bitset 压位。

时间复杂度 $O(K\log^2 K\frac NW)$。

但是：

spfa：[TLE 88](https://www.luogu.com.cn/record/124749538)

dijstra：[MLE 97](https://www.luogu.com.cn/record/124751447)

由于时间卡得很紧并且常数大，用死掉的 spfa 会 T；由于要手写 bitset，用 dijstra 每次入队时都要带一个$\frac NW$，多次入队空间会炸。

因此，要手写 zkw 线段树代替优先队列。
