## [B  数据结构在压轴](http://ac.hfoj.net/p/1839?tid=6535997def15be6f24895a2a)
![](Pasted%20image%2020231025073133.png)
![](Pasted%20image%2020231025073206.png)

**题解：**

诈骗题。

一个集合 $S$ 与其补集 $N/S$ 一定在中位数两侧，且 $f_S+F_{N/S}=\sum a_i$，只需找到第一个 $\ge \sum a_i$ 的集合和即可。

可以用 bitset 优化。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2005;
int t,n,a[N],s;
bitset<N*N>f,ff;
void work(){
	scanf("%d",&n),s=0,f.reset(),f[0]=1;
	for(int i=1;i<=n;++i) scanf("%d",&a[i]),ff=f,ff<<=a[i],f|=ff,s+=a[i];
	for(int i=(s+1)/2;i<=s;++i)if(f[i]){printf("%d\n",i);return;}
}
int main(){
	freopen("ds.in","r",stdin);
	freopen("ds.out","w",stdout);
	scanf("%d",&t);
	while(t--) work();
	return 0;
}
```

## [C  心灵治愈](http://ac.hfoj.net/p/1840?tid=6535997def15be6f24895a2a)
**题意：**

$T$ 组数据。每组给定 $n$ 个点 $m$ 条边的无向连通图，给每一条边上色（共三种颜色），问图中存在至少一条三色的简单路径（经过的点不重复）的染色方案数。

![](Pasted%20image%2020231025074242.png)

**题解：**

我们考虑求不存在三色路径的方案数。

- 全图没有三种颜色，方案数为 $2^m-3$
- 有三种颜色但无三色路径：
  1. 记去掉 $u$ 后连通块个数为 $x_u$，则方案数为 $3^{x_u}-2^{x_u}+3$。
  2. 只有不超过 $1$ 个点与外界相连的三元环贡献为 $6$。（三元环涂三种颜色，外界边与对边颜色相等）
  3. 两个三元环（无外接边）拼接在一起的有 $6$ 的贡献。![](Pasted%20image%2020231025075804.png)

$3^m$ 减去以上方案则为答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+5,p=998244353;
int t,n,m,x,y,tim,dfn[N],low[N],sz[N],ans;
vector<int>e[N];
stack<int>st;
void dfs(int u){
	dfn[u]=low[u]=++tim,st.push(u),sz[u]=0;
	for(int v:e[u]){
		if(!dfn[v]){
			dfs(v),low[u]=min(low[u],low[v]);
			if(low[v]==dfn[u]){
				++sz[u];
				while(st.top()!=u) ++sz[st.top()],st.pop();
			}
		}
		else low[u]=min(low[u],dfn[v]);
	}
}
int poww(int x,int y){
	int e=1;
	while(y){
		if(y&1) e=1ll*e*x%p;
		x=1ll*x*x%p,y>>=1;
	}
	return e;
}
void work(){
	scanf("%d%d",&n,&m),ans=(3ll*poww(2,m)+p-3)%p,tim=0;
	for(int i=1;i<=n;++i) e[i].clear(),dfn[i]=0;
	for(int i=1;i<=m;++i) scanf("%d%d",&x,&y),e[x].push_back(y),e[y].push_back(x);
	if(n<=3){printf("0\n");return;}
	dfs(1);
	for(int i=1;i<=n;++i){
		if(e[i].size()==2)for(int v:e[i])
			if(e[v].size()==2&&(i^v^e[i][0]^e[i][1]^e[v][0]^e[v][1])==0) (ans+=3)%=p;
		(ans+=(poww(3,sz[i])+p-3ll*poww(2,sz[i])%p+3)%p)%=p;
	}
	if(n==4&&m>=5) (ans+=6)%=p;
	ans=(poww(3,m)+p-ans)%p,printf("%d\n",ans);
}
int main(){
	freopen("heart.in","r",stdin);
	freopen("heart.out","w",stdout);
	scanf("%d",&t);
	while(t--) work();
	return 0;
}
```
