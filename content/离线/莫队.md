#离线 #分块

[莫队算法](https://oi-wiki.org//misc/mo-algo-intro/)
## 简介
莫队算法采用了[[分块]]的思想，可以解决一类离线区间询问问题，适用性极为广泛。同时将其加以扩展，便能轻松处理树上路径询问以及支持修改操作。

这是一个优美的暴力，常数较小，有时可以~~升维打击~~。
## 普通莫队
### 块长和复杂度
我们设块长度为 $S$，那么对于任意多个在同一块内的询问，挪动的距离就是 $n$，一共 $\displaystyle \frac{n}{S}$ 个块，移动的总次数就是 $\displaystyle \frac{n^2}{S}$，移动可能跨越块，所以还要加上一个 $mS$ 的复杂度，总复杂度为 $\displaystyle O\left(\frac{n^2}{S}+mS\right)$，我们要让这个值尽量小，那么就要将这两个项尽量相等，发现 $S$ 取 $\displaystyle \frac{n}{\sqrt{m}}$ 是最优的，此时复杂度为 $\displaystyle O\left(\frac{n^2}{\displaystyle \frac{n}{\sqrt{m}}}+m\left(\frac{n}{\sqrt{m}}\right)\right)=O(n\sqrt{m})$。

事实上，如果块长度的设定不准确，则莫队的时间复杂度会受到很大影响。例如，如果 $m$ 与 $\sqrt n$ 同阶，并且块长误设为 $\sqrt n$，则可以很容易构造出一组数据使其时间复杂度为 $O(n \sqrt n)$ 而不是正确的 $O(n)$。

莫队算法还有一个特点：当 $n$ 不变时，$m$ 越大，处理每次询问的平均转移代价就越小。一些其他的离线算法也具有同样的特点（如求 LCA 的 Tarjan 算法），但是莫队算法的平均转移代价随 $m$ 的变化最明显。
### 注意
- **<font color="#ff0000">代码中的移动区间的 4 个 while 循环的位置很关键，不能随意改变它们之间的位置关系。理应先 add(...) 后 del (...)。</font>**
- **<font color="#ff0000">小优化：询问按 $l$ 所在的块为第一关键字从小到大排序，以 $r$ 为第二关键字，当 $l$ 在奇块 $r$ 从小到大排序，当 $l$ 在偶块 $r$ 从大到小排序。</font>**

### 例题
#### [CF617E XOR and Favorite Number](https://www.luogu.com.cn/problem/CF617E)
**题面：**

- 给定 $n,m,k$ ，再给定一个长度为 $n$ 的序列 $a$，后给出 $m$ 组询问，每组询问给出一个区间，求这个区间里面有多少个子区间的异或值为 $k$。
- $1 \le n,m \le 10 ^ 5$，$0 \le k,a_i \le 10^6$，$1 \le l_i \le r_i \le n$。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int M=100005;
int n,m,k,b[M],ll,rr,fk;
long long a[M],ans[M],cnt[2097152],sum;
struct ques{int l,r,id;}q[M];
bool cmp(ques x,ques y){//奇偶优化
	return (b[x.l]==b[y.l])?((b[x.l]&1)?x.r<y.r:x.r>y.r):b[x.l]<b[y.l];
}
void add(int x){sum+=cnt[x^k],++cnt[x];}
void del(int x){--cnt[x],sum-=cnt[x^k];}
int main(){
	scanf("%d%d%d",&n,&m,&k);
	fk=n/sqrt(m)+1;
	for(int i=1;i<=n;++i) scanf("%lld",&a[i]),b[i]=i/fk,a[i]^=a[i-1];
	for(int i=1;i<=m;++i) scanf("%d%d",&q[i].l,&q[i].r),--q[i].l,q[i].id=i;
	sort(q+1,q+1+m,cmp);
	ll=1,rr=0;
	for(int i=1;i<=m;++i){ //先add后del
		while(ll>q[i].l) add(a[--ll]);
		while(rr<q[i].r) add(a[++rr]);
		while(ll<q[i].l) del(a[ll++]);
		while(rr>q[i].r) del(a[rr--]);
		ans[q[i].id]=sum;
	}
	for(int i=1;i<=m;++i) printf("%lld\n",ans[i]);
	return 0;
}
```

## 带修莫队
### 简介
普通莫队是不能带修改的，但可以强行加上一维 **时间维**, 表示这次操作的时间，即把询问 $[l,r]$ 变成 $[l,r,t]$，可以用和普通莫队类似的方法排序转移（不能奇偶优化）。
### 时间复杂度
可以做到 $O(n^{\frac{5}{3}})$。

以 $n^{\frac{2}{3}}$ 为一块，分成了 $n^{\frac{1}{3}}$ 块，第一关键字是左端点所在块，第二关键字是右端点所在块，第三关键字是时间。

证明一下时间复杂度：

- 左右端点所在块不变，时间在排序后单调向右移，这样的复杂度是 $O(n)$；
- 若左右端点所在块改变，时间一次最多会移动 $n$ 个格子，时间复杂度 $O(n)$；
- 左端点所在块一共有 $n^{\frac{1}{3}}$ 中，右端点也是 $n^{\frac{1}{3}}$ 种，一共 ${n^{\frac{1}{3}}}\times{n^{\frac{1}{3}}}=n^{\frac{2}{3}}$ 种，每种乘上移动的复杂度 $O(n)$，总复杂度 $O(n^{\frac{5}{3}})$。

### 例题
#### [P1903 [国家集训队] 数颜色 / 维护队列](https://www.luogu.com.cn/problem/P1903)
**题意：**

可进行以下两种操作：

![[Pasted image 20230922211436.png]]

对于所有数据，$n,m \leq 133333$

所有的输入数据中出现的所有整数均大于等于 $1$ 且不超过 $10^6$。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int M=133335;
int n,m,a[M],b[M],sq,sr,ll,rr,tt,fk,cnt[1000005],sum,ans[M];
char op;
struct ques{int l,r,id,ti;}qu[M]; 
struct revi{int p,c;}re[M];
bool cmp(ques x,ques y){//三维关键字排序 
	return b[x.l]==b[y.l]?(b[x.r]==b[y.r]?x.ti<y.ti:b[x.r]<b[y.r]):b[x.l]<b[y.l];
}
void add(int x){sum+=!cnt[x]++;}
void del(int x){sum-=!--cnt[x];}
void chan(int x){
	if(ll<=re[x].p&&re[x].p<=rr) add(re[x].c),del(a[re[x].p]);
	swap(a[re[x].p],re[x].c);
    //对于每次change，下一次change就是将两种颜色换回来，所以直接交换两种颜色就好 
}
int main(){
	scanf("%d%d",&n,&m);
	fk=pow(n,0.666666);
	for(int i=1;i<=n;++i) scanf("%d",&a[i]),b[i]=i/fk;
	for(int i=1;i<=m;++i){
		scanf("%s%d%d",&op,&ll,&rr);
		if(op=='Q') qu[++sq].id=sq,qu[sq].ti=sr,qu[sq].l=ll,qu[sq].r=rr;
		else re[++sr].p=ll,re[sr].c=rr;
	}
	sort(qu+1,qu+1+sq,cmp);
	ll=1,rr=tt=0;
	for(int i=1;i<=sq;++i){
		while(ll>qu[i].l) add(a[--ll]);
		while(rr<qu[i].r) add(a[++rr]);
		while(ll<qu[i].l) del(a[ll++]);
		while(rr>qu[i].r) del(a[rr--]);
		while(tt<qu[i].ti) chan(++tt);
		while(tt>qu[i].ti) chan(tt--);
		ans[qu[i].id]=sum;
	}
	for(int i=1;i<=sq;++i) printf("%d\n",ans[i]);
	return 0;
}
```
